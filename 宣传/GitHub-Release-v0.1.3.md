# 刷起 SHUAQI v0.1.3 · 判题刷新 + 版本更新 + 备份管理

这一版把「判题」和「数据安全」两条线补齐：改完答题框/补完笔迹再展开答题情况会自动重新识别；改卷会逐题核对当前 OCR，AI 原判不再被无脑打回；更新前自动备份、更新弹窗里可直接从备份恢复。

## 判题刷新

- 改过作答框、补写或擦除笔迹后，再展开「答题情况」会**自动重识别**，不用再手动点。
- 每道题保存判题依据（OCR 文本 + 作答指纹 + 参考答案哈希）：
  - AI 判过的题，答案没有明显改动 → 保留 AI 原判，不重复扣 token；
  - 改动很大（文本相似度 <80%、空↔非空、参考答案变了）→ 用当前 OCR 重判；
  - 手改结论永远保留。
- 「对答案」弹窗按钮改为「判题」「交给 AI 判」；低置信度的客观题可以按本地结论落判，结果里注明“请自行核对”；主观/公式仍保持黄点。
- 改卷逐题刷新 OCR + 核对；未作答单独计数，一道都没判出来时给汇总 +「去答题卡」。

## 首次启动用户须知

- 全新安装首次启动会弹「用户须知」，内容和「设置 → 关于 → 用户须知」是同一份。
- 勾选「我已阅读并知悉」后才能继续；确认后不再弹出，之后可随时到设置查看。
- **开屏须知/设置用户须知里都有「从备份恢复…」入口**：重装/换设备时可以先恢复数据，再同意；恢复前会先留底当前数据，完成后重启。
- 老用户升级不打扰。

## 版本检测与更新

- 版本说明顶部新增「版本更新」卡片：检查 GitHub Releases、显示新版本/更新内容/大小、下载并拉起系统安装器。
- 设置 tab 与「版本说明」入口会冒小红点；打开版本说明即清除。
- 后台检查：启动 3 秒后 + 回前台距上次 >6 小时 + 每 24 小时；不做常驻后台服务。
- **更新前自动备份**到「下载/SHUAQI」，命名 `SHUAQI_backup_before_v0.1.3_时间.zip`；备份失败会中止更新。
- 更新确认弹窗内直接提供「从备份恢复…」和「管理备份文件」；更新页的「数据安全与恢复」也有同样入口。
- 安装前校验包名 / versionCode / 签名；未允许「安装未知应用」时会引导去系统设置。
- 更新后如果本机没有试卷、但存在更新前备份，会询问是否恢复（不自动覆盖）。

## 备份管理

- 「导出备份」改为先弹窗：显示包含的卷/收藏/记录数，可改文件名，重名自动加 `-2`。
- 设置里的「缓存统计与清除」改名为「存储占用」：
  - 缓存：原有统计与清理（备份不算缓存，清理不碰备份）；
  - 备份文件：查看、恢复、重命名、删除；「更新前备份」置顶并打标。
- 「从备份恢复」先列出下载目录里的备份，也可继续从文件选择。

## 修复

- 设置滑到「关于」再进二级页，返回后不再跳回设置页顶端。
- 改卷不再拿旧识别文字判题，也不会把 AI 刚判完的主观题无脑打回黄点（除非答案明显改动）。
- 设置页子页返回、通知/弹窗层级等细节整理。

## 已知限制

- 版本检测需要联网访问 GitHub；没有网络或 GitHub 限流时不会弹红点，可在版本说明里手动重试。
- 应用内更新需要允许「安装未知应用」；安装包签名必须与本机一致，否则只能先导出备份再卸载重装。
- 备份列表只管理本应用当前安装创建的 `下载/SHUAQI` 备份；卸载重装后旧备份可用「从文件选择」恢复。
- 更新前备份会占用下载目录空间；恢复备份需要重启应用。
- 低置信度的本地判题会标绿/红并注明“请自行核对”；公式/主观题仍建议交给 AI 或手改。
- 更新检查只在应用运行时进行，不做常驻后台服务。
