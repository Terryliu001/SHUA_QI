## 0. 一句话

> **把纸质的 PDF 卷子，变成一本能写、能判、能二刷的电子题本。**

不是"PDF 阅读器 + 手写板"，也不是"题库 App"，而是两者之间那条一直没人做顺的路：
**原卷不动、笔迹在上面、题目被切出来、判完还能回到原卷**。

**目标设备**：Android 平板 + 手写笔（横屏最舒服；手机能跑但挤）。
**目标人群**：考研 / 高考复读 / 考证（法考、教资、CPA）这类**长期刷纸质 PDF 卷子**的人，以及自己做讲义的老师。

## 1. 有效功能清单

### 1.1 书架（导入与管理）

| 能力 | 程度 | 落点 / 限制 |
|---|---|---|
| 导入 PDF（可多选批量） | ✅ | 系统文件选择器，`allowMultiple` |
| 同一份卷不会重复导入（内容指纹） | ✅ | 流式 SHA-1 比对，命中直接跳到已有卷 |
| 三种视图：列表 / 大图 / 树形 | ✅ | 树形是 Obsidian 式单栏树，文件夹可嵌套 |
| 卡片大小三档 + 双指捏合缩放卡片 | ✅ | 捏合调档并持久化 |
| 排序：最近打开 / 标题 / 页数 | ✅ | 全局记住 |
| 文件夹：嵌套、改名、拖动改归属 | ✅ | 独立表（v4），不是靠字符串字段 |
| 标签：卡片右上角"书签"形态、可自定配色 | ✅ | 不占布局，按名字稳定配色 |
| 搜索：标题 / 标签 / 文件夹 | ✅ | 书架与收藏夹各一套 |
| 多选 + 批量移动 / 删除 / 导出 | ✅ | 多选态返回键只退出多选 |
| 缺缩略图时按需重建 | ✅ | 串行队列渲染第 0 页并原子写回；清缓存后不会整排空白 |
| 导出 PDF（纯 Dart 生成，无外部依赖） | ✅ | 原题 / 笔迹 / 答题卡任意组合，4 个预设，文件名可改；落 `Download/SHUAQI` |
| 损坏文件的降级 | ✅ | 卡片置灰 + 明确提示，不阻塞其它卷 |

### 1.2 阅读器（读 + 写）

| 能力 | 程度 | 落点 / 限制 |
|---|---|---|
| 分页 / 连续滚动（可缩放卷轴） | ✅ | 缩放 45%–400%，默认 86%；斜向滑动有轴向锁定 |
| 单指平移 + 双指缩放 | ✅ | 手势模式：手指只平移缩放、笔才写字；关掉则手指也能写 |
| 四支笔：钢笔 / 圆珠笔 / 荧光笔 / 橡皮 | ✅ | 每支笔**分别记住**颜色与粗细 |
| 局部橡皮（切开笔画，不是整笔删） | ✅ | 三档橡皮大小；一次拖动合成一步撤销 |
| 撤销 / 重做 / 立即保存 | ✅ | 命令栈 50 步；落笔即入栈 |
| 笔尖 HUD：真实笔触样本 + 数值 | ✅ | 粗细滑条右侧直接画出这一档的笔触 |
| 图形吸附（画完自动变规整） | ✅ | 直线 / 矩形 / 正方形 / 圆 / 椭圆 / 直角三角 / 等腰三角 / 平行四边形；停笔 500ms 预览、移动取消、抬笔确认；只在钢笔与圆珠笔生效 |
| 自动切题（文本层 + 扫描件两套） | ✅ | 扫描件靠行/题号启发式；`question.id` 跨重切稳定 |
| 框的编辑：切分 / 并入 / 跨页 / 改题号 / 锁定 / 删除 | ✅ | 锁定 = 重新切题不覆盖它 |
| 题目区域面板 | ✅ | 题目列表、缩略预览、答题卡入口、收藏、对答案、判题指示灯；宽度可拖，跨卷记住 |
| 缩略图抽屉 | ✅ | 长卷跳页 |
| 显示设置：6 种纸感 + 强度 + 夜读 | ✅ | 原图 / 暖白 / 象牙 / 灰 / 绿 / 夜读（duotone 暖黑纸）；**只染卷面，不影响界面主题** |
| 题面长按存图 | ✅ | 两档清晰度；走系统媒体库 |
| 页面内存策略 | ✅ | 位图按字节 LRU（320MB 上限）+ 前后页预热，翻页无白屏 |

### 1.3 作答与判题

| 能力 | 程度 | 落点 / 限制 |
|---|---|---|
| 答题卡：每题一个作答框 | ✅ | 每题独立笔迹文件；答题纸可选尺寸 / 方向 / 张数 / 纸张样式 |
| 手写识别（本地 OCR） | ⚠️ | ML Kit 数字墨水；**首次需联网下载模型**，无 GMS 时降级为"原图仍保留" |
| 本地判题（不联网也能判） | ✅ | 选择题 / 数值等价 / OCR 置信度 ≥0.65 直接出结论 |
| 三态结论：对 / 待判 / 错 | ✅ | `AnswerVerdict = correct / pending / wrong`；待判用琥珀色（不等于"错"），点一下可询问 AI |
| 「改卷」批量判 | ✅ | 只跑有答案的题；本地先判，判不了才问 AI；后台逐题、有进度、可停 |
| 手改结论永远优先 | ✅ | `source=manual` 不被 AI 覆盖 |
| 无答案 / 无作答的明确门禁 | ✅ | 无答案 → 按钮置灰并说明；有答案没写 → 只展示答案 |
| **总成绩 / 交卷报告** | ❌ | **没有**"交卷 → 总分 / 报告"页面。这是当前最明显的功能缺口 |

### 1.4 收藏夹（错题 → 二刷）

| 能力 | 程度 | 落点 / 限制 |
|---|---|---|
| 单题 / 批量收藏（跨卷快照） | ✅ | 收藏是快照，原卷删了也还在 |
| 四种视图：全部题卡 / 按试卷 / 按知识点 / 组卷 | ✅ | 选择跟随当前视图 |
| 知识点：手动编辑 + AI 归纳（先确认再落） | ✅ | AI 只给建议，逐题增减后才写入 |
| 组卷（多选建卷 → 连刷 → 拖动排序） | ✅ | 一次 run 共用一个 attempt |
| 二刷 / 重刷（空白答题卡） | ✅ | 每次独立 attempt；退出可"保存 / 不保存 / 继续写"；列表可回看 |
| 看题页：题面 + 你的作答 + 判定 + 问 AI | ✅ | 可"回看出处"精确跳回原卷那道题 |
| 批量取消收藏 | ✅ | 全收藏 = 取消、混合 = 只补缺（不偷偷删） |

### 1.5 记录（行为回顾，不是社交主页）

| 能力 | 程度 | 落点 / 限制 |
|---|---|---|
| 个人空间：头像 / 封面（可裁剪）/ 昵称 / 格言 | ✅ | 裁剪窗整图可见、不变形；封面比例按页首实宽 |
| 26 周热力图（可切 13 / 26 / 52 周） | ✅ | 点格子看当天小结 |
| 科目 / 题型词云 | ✅ | 手指搅动像沙盘，松手弹性归位 |
| 7 天 / 30 天看板 | ✅ | 题量、正确率、活跃天数 |
| 连续打卡（火苗三档） | ✅ | 有分档文案，不羞辱断签 |
| 作答时间线（按试卷 / 按题目） | ✅ | 点卡直接回原卷；重刷卡回到**那一次** attempt |

| 能力 | 程度 | 落点 / 限制 |

| AI 归纳知识点 | ✅ | 结果必须先确认 |
| 用量统计 | ✅ | 次数 / 输入 / 输出 token |

### 1.7 设置与数据

| 能力 | 程度 | 落点 / 限制 |
|---|---|---|
| 主题：跟随系统 / 浅 / 深 | ✅ | 深色只影响界面骨架，不影响卷面 |
| **5 套色系**：靛蓝 / 青瓷 / 紫藤 / 赭陶 / 石墨 | ✅ | 2026-10-26 新增；只换强调色，灰阶与纸感不动 |
| 文字模式（图标 + 文字） | ✅ | 全局开关 |
| 阅读默认（翻页方式 / 手势 / 纸感 / 强度） | ✅ | 只影响之后新开的卷 |
| 工具条形态（固定顶栏 / 右下浮钮） | ✅ | 浮钮给最干净的阅读区 |
| 缓存统计与分项清除 | ✅ | 只清可再生缓存 |
| 导出备份 / 从备份恢复 | ✅ | 流式 zip，含库 + 卷 + 笔迹 + 收藏；恢复前先留底 |
| 使用指南 / 版本说明 / 用户须知 | ✅ | 应用内二级页 |
| 用户反馈 | ⚠️ | 已有表单与草稿兜底，但**服务端未部署**，目前只存本机 |
| 开发者选项 | ✅ | 版本号连点 8 次解锁 |

### 1.8 工程底座（用户看不见，但决定体验）

- **全本机**：无账号、无云同步、无埋点上传；PDF、笔迹、判题全在 App 私有目录。
- **笔迹格式自研**：zlib + CRC + 0.1pt 定点 + 4bit 压力，500ms 防抖**原子写**（`.tmp` → rename）+ `.bak`。
- **数据可迁移**：DB 迁移只追加（现已到 v9），升级不丢数据。
- **分层有测试守**：`ui → state → domain`、`domain` 纯 Dart，架构测试把关；宿主测试基线 639 passed（3 个 pdfrx 既存失败，非本项目逻辑）。
- **无广告、无内购、无注册**。

## 2. 产品特色（对外就讲这几条）

### ① 在"真卷子"上写，不是在一张白纸上
底图是原 PDF，笔迹是独立图层，缩放不糊、翻页不丢；橡皮是**切开笔画**的局部擦除。
👉 用户感受：**不用打印、不用扫描，习惯不用改。**

### ② 卷子会被"切开"成一道一道题
自动切题 + 手调框 + 每题独立作答框。这一步是**从"看 PDF"跨到"做题"**的分水岭 ——
只有切成题，才可能有判题、错题本、知识点、组卷。
👉 用户感受：**同一份卷子，第一次变得可统计。**

### ③ 判题先本地，判不了才问 AI
选择题/数值题不联网就能判；不可信才标黄点问 AI；手改永远盖过 AI。
👉 用户感受：**省钱、离线可用、结论敢信。**

### ④ AI 是加分项，不是入场券
自带 Key、任意 OpenAI 兼容端点，不充会员、不看广告。
👉 用户感受：**不用为"AI 功能"付订阅费**，也能完全不用 AI。

### ⑤ 错题会自己长成"第二本卷子"
收藏 → 知识点 → 组卷 → 空白二刷 → 记录这一次的表现。
👉 用户感受：**错题不是收藏夹里的尸体，是能重做的卷子。**

### ⑥ 记录的是"行为"，不是"打卡海报"
热力图、词云、时间线都指回具体某天某卷某题。
👉 用户感受：**知道自己到底练了多少、练在哪。**

### ⑦ 数据是自己的
全本机 + 一键 zip 备份，卸载前能带走，换机不靠云。
👉 用户感受：**没有"账号丢了资料就没了"的恐惧。**

## 3. 和谁不一样（一句话对照）

| 产品类型 | 代表 | 它的强项 | 它的空缺（本产品的机会） |
|---|---|---|---|
| 手写笔记 | GoodNotes / Notability / 三星笔记 | 笔感好、生态成熟 | 不懂"题"，没有判题/错题/组卷 |
| PDF 精读 | MarginNote / LiquidText | 摘录与脑图强 | 不做答题卡，不判题 |
| 题库/背题 | Anki / 各类刷题 App | 有题库、有算法 | 只能用它的题，**不能用自己的 PDF 卷子** |
| 搜题 | 小猿 / 作业帮 | 拍题即答 | 解题 ≠ 练习，不留笔迹、不进错题本 |
| 纸质 | 打印 + 红笔 | 无可替代的手感 | 不能统计、不能二刷、不能带走 |

> **本产品的生态位**：**你自己的 PDF 卷子 + 真手写 + 判题 + 二刷**。
> 一句对外话术：**"题库 App 只能用它的题，我们能用你的卷子。"**

## 4. 宣发建议

### 4.1 核心信息（先定这三句，所有素材都围绕它）

- **主标题**：把你的 PDF 卷子，变成能判分的题本
- **副标题**：真手写 · 自动切题 · 判题二刷 · 数据全在本机
- **反对句**（制造记忆点）：**"题库 App 只能用它的题 —— 我们能用你的卷子。"**

三个必须反复讲的证据点：**切片演示（切题）→ 判题演示（三态灯）→ 二刷演示（空白重做）**。
这三个镜头是别人没有的，其余（笔感、纸感、夜间）都是"也做得不错"。

### 4.2 必拍的 6 个镜头（按顺序剪成 45 秒）

1. 书架导入一份真实 PDF（2 秒，露出"已导入"）
2. 打开卷子，笔一落，字就出来（3 秒，笔迹跟手）
3. 橡皮切开笔画（2 秒，反差感最强的一个细节）
4. 点一下"题目区域"，一页卷子**裂成 8 个题框**（5 秒，核心镜头）
5. 答题卡写两笔 → 点"改卷" → 三态灯亮起（5 秒）
6. 收藏这道题 → 组卷 → 空白二刷（8 秒）
> 结尾 3 秒：`设置 → 色系` 五个色点依次点亮（"这玩意儿还挺好看"的记忆点）

### 4.3 内容矩阵（按投产比排）

| 平台 | 内容形态 | 具体选题 |
|---|---|---|
| **B 站** | 3–8 分钟长视频 | 「我怎么用一台平板刷完 30 套真题」全流程；「PDF 卷子怎么变成错题本」 |
| **小红书** | 图文 6–9 图 + 15 秒竖屏 | 「考研人的卷子管理法」「平板刷题不打印」；重点拍纸感/夜间/色系 |
| **知乎** | 长答案 | 「有哪些相见恨晚的考研工具」「iPad/安卓平板刷题怎么选」下埋点 |
| **抖音** | 15–30 秒 | 只放第 4 个镜头（切题）+ 第 3 个（橡皮切开） |
| **公众号** | 一篇深度 | 「为什么题库 App 帮不了你」——把 §3 的对照表写成故事 |
| **垂类社区** | 考研帮 / 一亩三分地 / 法考群 | 冷启动招内测，不谈功能先收反馈 |

### 4.4 可直接用的短文案

**A（应用商店 / 官网一行）**
> 刷起 SHUAQI —— 用你自己的 PDF 卷子刷题：真手写、自动切题、判完还能二刷。数据只在你机器上。

**B（小红书风）**
> 把 30 套真题塞进一台平板，不用打印、不用扫。
> 写起来是笔的感觉，判完会告诉哪几道错，错题攒着还能组一套新的再刷一遍。
> 最爽的是：卷子还是我自己那些卷子。

**C（知乎/B 站简介）**
> 一个不联网也能判题的刷题工具。PDF 是你的，笔迹是你的，AI 是可选项。

**D（商店描述草稿，约 180 字）**
> 刷起是一款面向「自己的卷子」的刷题工具。导入 PDF 试卷后，它会自动把页面切成一道道题，
> 你可以用手写笔直接在卷面上作答、用局部的橡皮改错、用图形吸附把草稿画规整。
> 答完点"改卷"：选择题与数值题本地即可判，判不了的再交给 AI（用你自己的 API Key）。
> 判完的题可以收藏、打知识点、组成新卷子，用空白答题卡二刷。
> 记录页会告诉你最近练了多少、错在哪。全程不联网、不需要账号，数据保存在设备上，可一键备份。

### 4.5 冷启动路径

1. **内测 20 人**（考研/考证群各 10 人）：目标是"能不能坚持用一周"，不是夸功能。
2. **1–2 位学习区 UP 主**：给"真实卷子 + 真实使用一个月"的素材，不要脚本口播。
3. **垂类社区长贴**：一篇讲清"为什么题库 App 用不了自己的卷子"。
4. **再考虑应用市场**（见 §5 阻塞项）。

### 4.6 合规红线（比流量重要）

- **试卷版权**：宣传里不出现任何出版社/机构的完整卷面；演示用自制或已授权试卷。
- **AI Key**：明确写"你填自己的 Key，请求直接发往你填的地址，我们不中转"。
- **隐私**：不注册、不上传；隐私政策要把"本机存储"写成第一句。
- **未成年人**：不做"提分保证""押题"这类承诺。
- **不假称功能**：公式题目前"只给图"、没有总分报告 —— 宣传里不要暗示有。

### 4.7 不建议的宣发方式

- 不要打"AI 一键解题"（会让人以为是小猿类产品，且我们的 AI 是 BYOK，体验取决于用户 Key）。
- 不要比笔感参数（对 GoodNotes 用户没意义，反而是对方主场）。
- 不要在没做交卷结果页前宣传"模拟考试/成绩分析"。
- 不要投信息流（客单价 0、无内购，投产比撑不住）。

## 5. 宣发前必须先补的三件事

| 优先级 | 事项 | 为什么挡住宣发 |
