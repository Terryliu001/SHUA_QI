## 这一版改了什么

### 1. 用户反馈真正接通（设置 → 关于 → 用户反馈）

之前点「提交」只会把内容存在本机并提示"通道未接通"。现在：

- **真的会送到开发者**：文字 + 最多 3 张截图 → 开发者的**私有**反馈仓库；
- **先存本机再发送**：网络失败 / 进程被杀都不会丢你写的东西；
- **「我提过的反馈」**：每条都能看到「待发送 / 已送达 / 发送失败」、失败原因、远端 issue 号，
  可以手动重试、删除、一键复制；
- **自动补发**：回到前台或下次启动时会重试之前没发出去的；
- 反馈里会带 **App 版本 + 设备型号 + Android 版本**（如 `OPPO OPD2601 / Android 16 / API 36`），
  方便定位；**不取** IMEI / 序列号 / 广告 id 等任何设备标识符；
- 手机号仍然**选填**，只在私有记录里出现（公开页面与公开仓库都看不到）。

> 隐私口径：反馈只在你点「提交」时上传，内容只进开发者的私有反馈仓库；
> 除你主动配置的 AI 请求与这次反馈外，应用不发起任何网络连接。

### 2. 头像圆形框修复

之前裁完头像，圆形头像框里还能看到**方形的裁切直边**（图没有铺满圆框）。
根因是"边框被算成了图片的内边距"：图片实际只有 73×73，而裁剪圆是 78 —— 圆的四条边落到了图外面。

现在：

- 边框画在图片**上层**，图片按 78×78 铺满再被圆裁掉，**圆框里 100% 是图**；
- 头像输出本身也改成**圆形**（圆外透明），以后任何界面都不会再露出方形边界；
- 封面仍是直角矩形，不受影响。

## 安装

| 项 | 值 |
|---|---|
| 文件 | `shuaqi-0.1.1.apk`（`app-arm64-v8a-release.apk` 重命名） |
| 版本 | 0.1.1（2） |
| 系统 | Android 8.0 及以上（**只含 arm64**） |
| 建议设备 | 10 寸以上平板 + 手写笔 |
| 大小 | 36.7 MB（38,509,535 字节） |
| SHA-256 | `244DA34279E628F0C50E4D4C7A0D9ECC5FF8BBBB42DDBC1A404BE013FFB46029` |
| 签名 | 与 v0.1.0 相同的 release 密钥（可直接覆盖安装，数据保留） |

安装步骤：下载 → 允许"安装未知来源应用" → 安装。
> 从更早的 debug 签名版本升级仍需先卸载（卸载会删数据，先导出备份）。

## 第一次用，三步

1. **书架 → 右下角导入** 一份 PDF 试卷
2. 打开卷子 → 顶栏「**题目**」→ 查看自动切题结果，切歪了就地拖框调整
3. 写完后 → 顶栏「**答题卡**」→「**改卷**」→ 回到卷面看三态灯

## AI 是可选的

- 不配 AI 也能用：选择题、数值题在本地就能判。
- 想用：设置 → AI 配置，填你自己的端点 / Key / 模型（内置 DeepSeek、Kimi、混元、智谱预设）。
- Key 只存在本机；请求**直接发往你填的地址**，本项目不做任何中转。

## 已知限制（诚实清单）

- **公式题目前只能看图**，没有公式识别
- **没有「交卷 → 总分 / 报告」页面**
- 手写识别首次使用需联网下载模型；设备无 GMS 时会降级
- **反馈没有回复通知**：开发者回复后不会在 App 内推送
- 只有 Android / arm64；没有 iOS、桌面版、多设备同步
- 界面按平板横屏设计，手机竖屏能用但很挤

## 反馈

- 应用内：设置 → 关于 → 用户反馈（**这一版真的能发出去了**）
- 或直接开 Issue。**请不要贴真实姓名、手机号、完整试卷**（版权 + 隐私）。
