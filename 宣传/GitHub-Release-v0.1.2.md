## 这一版改了什么

### 虚线框上点「加题」= 就地确认

切题拿不准的块会画成**虚线框**（可能是大题容器，也可能就是一道题）。现在：

- **题号不变**：原来标着「八、」，确认后还是「八、」，不会再变成"现有最大题号 +1"；
- **在题目面板里的位置不变**：不会再跳到列表末尾；
- **题目 id 不变**：同一道题的判题、收藏、作答记录不会因为 id 变化而断开；
- **只去掉虚线**：确认后就是一道普通题（实线框），并计入可作答题；
- **立刻变**：确认后虚线框当场变实线，不用关面板再开。

> 实线题上点「加题」仍然是"在本题下方新增一道题"（题号接现有最大号之后），
> 这个语义没变。

## 安装

| 项 | 值 |
|---|---|
| 文件 | `shuaqi-0.1.2.apk`（`app-arm64-v8a-release.apk` 重命名） |
| 版本 | 0.1.2（3） |
| 系统 | Android 8.0 及以上（**只含 arm64**） |
| 建议设备 | 10 寸以上平板 + 手写笔 |
| 大小 | 36.7 MB（38,509,535 字节） |
| SHA-256 | `A30425EB58EBE748098E620DDED350125357964EEE10F7E8DFA33B6230BFB6B6` |
| 签名 | 与 v0.1.0 / v0.1.1 相同的 release 密钥（可直接覆盖安装，数据保留） |

安装步骤：下载 → 允许"安装未知来源应用" → 安装。
> 从更早的 debug 签名版本升级仍需先卸载（卸载会删数据，先导出备份）。

## 第一次用，三步

1. **书架 → 右下角导入** 一份 PDF 试卷
2. 打开卷子 → 顶栏「**题目**」→ 查看自动切题结果，切歪了就地拖框调整
3. 写完后 → 顶栏「**答题卡**」→「**改卷**」→ 回到卷面看三态灯

## AI 是可选的

- 不配 AI 也能用：选择题、数值题在本地就能判。
- 想用：设置 → AI 配置，填你自己的端点 / Key / 模型（内置 DeepSeek、Kimi、混元、智谱预设）。
- Key 只存在本机；请求**直接发往你填的地址**，本项目不做任何中转。

## 已知限制（诚实清单）

- **公式题目前只能看图**，没有公式识别
- **没有「交卷 → 总分 / 报告」页面**
- 手写识别首次使用需联网下载模型；设备无 GMS 时会降级
- 反馈没有回复通知：开发者回复后不会在 App 内推送
- 只有 Android / arm64；没有 iOS、桌面版、多设备同步
- 界面按平板横屏设计，手机竖屏能用但很挤

## 反馈

- 应用内：设置 → 关于 → 用户反馈（0.1.1 起真正可送达）
- 或直接开 Issue。**请不要贴真实姓名、手机号、完整试卷**（版权 + 隐私）。
