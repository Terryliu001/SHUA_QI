# 刷起 SHUAQI v0.1.0 · 首个公开内测

**把你的 PDF 卷子，变成能判分、能二刷的题本。**

> 题库 App 只能用它的题 —— 刷起能用你自己的卷子。

![书架](待插图-01-hero)

---

## 这是什么

一个 Android 平板上的刷题工具：**导入你自己的 PDF 试卷**，用手写笔直接在卷面上写，
它会自动把页面切成一道道题，给出对 / 待判 / 错，判完的题可以收藏、组成新卷子、用空白答题卡再刷一遍。

不需要账号，不需要联网，不上传任何卷子。

## 这一版能做什么

- **导入自己的 PDF**（可多选，同一份卷子不会重复导入），书架支持列表 / 大图 / 树形三种视图、嵌套文件夹、标签
- **直接在卷面上手写**：钢笔 / 圆珠笔 / 荧光笔 / 橡皮，橡皮是**切开笔画**的局部擦除，不是整笔删
- **一页卷子自动切成一道道题**，切歪了可以手调（切分 / 并入 / 跨页 / 改题号 / 锁定）
- **每题独立答题卡**：判题先本地跑（选择题、数值题离线就能判），判不了的才交给你自己的 AI
- **对 / 待判 / 错 三态灯**，支持一键改卷（后台逐题、有进度、可随时停）；手改的结论永远优先
- **收藏 → 知识点 → 组卷 → 空白二刷**：错题会自己长成第二本卷子
- **记录页**：13/26/52 周热力图、科目词云、7/30 天看板、作答时间线（点一下回到那天那道题）
- **6 种纸感 + 夜读 + 5 套配色**（靛蓝 / 青瓷 / 紫藤 / 赭陶 / 石墨）

## 安装

| 项 | 值 |
|---|---|
| 文件 | `shuaqi-0.1.0.apk`（`app-arm64-v8a-release.apk` 重命名） |
| 系统 | Android 8.0 及以上（**只含 arm64**） |
| 建议设备 | 10 寸以上平板 + 手写笔（手机能跑，但界面偏挤） |
| 大小 | 36.6 MB（38,378,383 字节） |
| SHA256 | `467B346CCBD06E343EEFE1A3F3FED126246A9F56D931157532235E28DB64907A` |

安装步骤：下载 → 允许"安装未知来源应用" → 安装 → 首次打开会建库（几秒内）。
> 这是 **0.1.0 内测包，已用 release 密钥签名**。如果你装过更早的 debug 签名版本，
> 两个包签名不同、不能覆盖安装，需要先卸载 —— 卸载会删掉本机数据，请先导出备份。

## 第一次用，三步

1. **书架 → 右下角导入** 一份 PDF 试卷
2. 打开卷子 → 顶栏「**题目**」→ 查看自动切题结果，切歪了就地拖框调整
3. 写完后 → 顶栏「**答题卡**」→「**改卷**」→ 回到卷面看三态灯

## AI 是可选的

- **不配 AI 也能用**：选择题、数值题在本地就能判。
- 想用：设置 → AI 配置，填你自己的端点 / Key / 模型（内置 DeepSeek、Kimi、混元、智谱预设）。
- Key 只存在本机；请求**直接发往你填的地址**，本项目不做任何中转，也不收集。

## 数据与隐私

- 无账号、无云同步、无埋点上报；卷子、笔迹、判题结果都在应用私有目录。
- 卸载会**一起删掉**本机数据 —— 重要资料请先在 设置 → 数据 → **导出备份**。

## 已知限制（诚实清单）

- **公式题目前只能看图**，没有公式识别（下一版）
- **还没有"交卷 → 总分 / 报告"页面**：单个题目能判，但没有整卷成绩单
- 手写识别首次使用需联网下载模型；设备无 GMS 时会降级（原图仍保留，可人工判）
- 用户反馈通道尚未接通服务端，反馈目前**只存本机**
- 只有 Android / arm64；没有 iOS、没有桌面版、没有多设备同步
- 界面按平板横屏设计，手机竖屏能用但很挤

## 反馈

- 应用内：设置 → 关于 → 用户反馈
- 或直接开 Issue。**请不要贴真实姓名、手机号、完整试卷**（版权 + 隐私）。
