# SHUAQI 演示脚本（12 步）

> 用途：最终真机彩排 / 录屏。按顺序走，每步一句话解说；失败就记下现象，不硬演。
> 设备：OPPO OPD2601（平板，横屏）。演示数据：卷子至少 2 份、1 道收藏、1 次重刷。

1. **书架**：启动 → 5 张卷卡有卷面缩略图；顶部文件夹/标签/搜索/视图。
2. **导入**：右下「导入 PDF」→ 选一份；进度显示；重复文件被拦。
3. **阅读**：打开卷 → 连续滚动 / 分页切换；缩放 86%→120%；纸感/夜读各停 2 秒。
4. **书写**：钢笔写一行 → 圆珠笔换色写 → 荧光笔划过 → 橡皮局部擦 → 撤销/重做。
5. **图形吸附**：钢笔慢慢画一个矩形，**停笔约半秒**出现「矩形 · 松手确认」→ 抬笔变成规整矩形；再画一条斜线，继续移动取消吸附。
6. **切题**：题目区域 → 点一条题跳转；拖框/拉角；锁定后拖不动、只剩改题号；解锁恢复；改题号。
7. **答题卡**：顶栏「答题卡」→ 写两笔 → 展开「答题情况」；「重框」拖的是题目框，返回自动保存。
8. **判题**：选中「有答案」的题 → 对答案（本地结论 + 指示灯）；无答案题按钮置灰；工具行「改卷」→ 本地汇总 → 如弹窗选「先这样」；多选 → AI 判（有 Key 再真跑）。
9. **收藏与重刷**：收藏一道题 → 看题页「重刷这道题」打开**空白**答题卡 → 写一笔 → 返回弹「保存这次重刷记录？」→ 保存 → 列表出现该次；再点开可继续改；时间线「重刷」卡展开也能打开。
10. **记录**：热力图切近三个月/一年；词云拖一个词 → 松手回弹；时间线按试卷/按题目。
11. **导出 PDF**：书架长按 → 导出 → 选「完整存档」→ 文件名改成自己的 → 导出 → 「下载/SHUAQI」里能看到，打开检查页数与清晰度。
12. **设置/帮助**：设置 → 关于：使用指南 / 版本说明 / 用户须知 / 用户反馈四条；AI 配置 info 看 DeepSeek 模型对比；缓存统计清除；AI 配置测试连接。
