## 3. 一个刻意的取舍：缩略图用 PNG 而不是 JPEG

规格写的是「JPEG q80」，但 **Flutter 引擎只能把 `ui.Image` 编成 PNG / raw RGBA，没有 JPEG 编码器**。
要用 JPEG 就得引 `image` 包——**不在白名单**。

于是选择用 PNG，代价是单张缩略图约 30–60KB（JPEG 约 10KB）。
20 份卷 × 4 张 × 50KB ≈ 4MB，对整体存储无感，**换来的是零新增依赖**。
若以后存储压力真的上来，再引 `image` 包做一次批量重编码即可（缩略图可以随时重建）。

## 5. 两个坑

### 5.1 `file_picker` 13 起 API 变了

13.0 之后不再是 `FilePicker.platform.pickFiles()` → `FilePickerResult`，而是：
```dart
final List<PlatformFile> files = await FilePicker.pickFiles(...);   // 静态方法
```
`FilePickerResult` / `FilePicker.platform` 都已不存在，编译期直接报 undefined。

### 5.2 每次验证 10 分钟的根因（已记进 MEMORY）

不是网慢，也不是 pdfium 下载。是 `flutter test integration_test -d 设备` **每次都要重新构建并安装整个 debug APK**，
而 debug APK 在这套 Flutter 上固定 ~144MB，其中 `kernel_blob.bin` 就占 **118MB**（引擎基线，与业务代码无关）。

节奏改成：

| 场景 | 做法 | 耗时 |
|---|---|---|
| 日常跑起来看 | `flutter run --profile --target-platform android-arm64 -d <设备>` | 构建 ~60s + 安装 ~10s，之后热重启秒级 |
| 宿主机单测 | `bash tool/run_tests.sh` | 秒级 |
| 数据库 / 导入这类关键逻辑 | `flutter test integration_test/xxx.dart -d <设备>` | ~10 分钟，**只在里程碑跑** |

另外：`build.gradle.kts` 里的 `ndk { abiFilters }` **无效**——Flutter 会注入 `-Ptarget-platform` 覆盖它，
收敛 ABI 只能靠命令行参数。

### 5.3 测试金字塔又调整了一次

pdfrx 回到 `dependencies` 后，**宿主机 `flutter test` 连"纯 Dart"测试也跑不了**：
它不再是因为编译失败而挂，而是**启动前就拒绝**（`Package(s) ... require the dart assets feature`）。
也就是说「关掉 native assets 再跑」这条路彻底堵死。

最终形态：

| 测试 | 位置 | 怎么跑 | 现状 |
|---|---|---|---|
| 架构约束 / ULID / ReaderPrefs | `test/`（纯 Dart） | `bash tool/run_tests.sh`（跑前临时摘掉 pdfrx） | **16 passed** |
| Widget / DB / 导入 | `integration_test/` | `flutter test ... -d <设备>` | DB 10 + 导入 2 + Widget 3 |
| 一切改动 | — | `flutter analyze` | 零 issue |

`tool/run_tests.sh` 会在跑测试期间把 `pdfrx` 那一行临时换成注释，跑完（含 Ctrl-C）自动恢复并 `pub get`。
代价是每次多两次 pub get（3–5 秒），换来的是**秒级的 domain 测试反馈**——这是后面几何/判题/公式逻辑的命根子。

## 7. 下一步：T1.5 阅读器

T1.3 之后，"打开一份卷看到题"只差阅读器。T1.4 的剩余部分（搜索、长按菜单、下拉刷新、横屏三列）
是打磨，可以押后。

T1.5 的关键决策点（T0.4 已经给出数据）：

1. **屏显必须走 `ui.Image` 而不是 PNG**：渲染 3ms vs PNG 编码 120ms，翻页体验差一个数量级。
   契约 `renderPage` 返回 `Uint8List` 仍保留给导出/OCR 用，阅读器内部走 `renderRaw`。
2. **400% 缩放必须分块**：整页 10px/pt 是 191MB 位图。做法是按视口裁块渲染（实测 4ms/块），
   缓存键 `(page, scaleBucket, tileX, tileY)`。
3. 分页用 `PageView` + 页内 `InteractiveViewer`；滚动用 `CustomScrollView`（不要让 InteractiveViewer 包整个列表）。
4. 主可见页按"与视口中线重叠面积最大"取，不要用 `offset / pageHeight`（A4/A3 混排会错）。
