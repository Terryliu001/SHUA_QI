## 1. 笔尖提示（参考圈）为什么对钢笔"没反应"

根因：第一版把**圈的直径画成真实笔尖大小**。
钢笔 0.86 倍下最细档是 `0.8pt × 1.42 × 2 ≈ 2.3dp` —— 屏幕上 8 个像素，
等于没提示；而荧光笔/橡皮半径 12–28pt，圈很大，所以"只有大笔刷看得见"。

修法（`_HaloLayer`）改成**两个元素**：

| 元素 | 尺寸 | 作用 |
|---|---|---|
| 实心点 | **真实笔尖/橡皮大小**（最小 3dp） | "这一笔有多粗"——参考的语义 |
| 定位环 | `max(真实大小, 26dp)` | 把视线钉在"最后落笔的位置"（细笔也看得见） |

钢笔/圆珠笔/荧光笔/橡皮四种都验过：细笔是小点在环里，荧光笔/橡皮的环跟着真实尺寸变大。

## 2. 提示动画：从"硬出现/硬消失"改成进出场

第一版是 `ValueNotifier<Offset?>` 直接切换（出现=瞬现、1.4s 后=瞬消），用户说"不自然、隐退没做好"。
现在用 `AnimationController`（160ms 进 / 260ms 出）：

- **进**：淡入 0→1 + 轻微放大 88%→100%（`easeOutCubic`）——像"浮起来"；
- **停留**：1100ms；
- **出**：淡出 + 缩回，**淡出结束才拆位置**（避免"消失瞬间还能看到一点"）；
- 换位置（改粗细连点几次）会从当前进度续播，不闪。

## 3. 滚动边界：从"撞墙"改成"皮筋 + 弹簧"

原来是硬夹紧：`clampOffset` 把越界量直接砍掉，甩到边界 `ticker.stop()` —— 手感是撞墙。

现在三层：

| 场景 | 行为 |
|---|---|
| 拖动越界 | **橡皮筋**：`f(o) = (1 − 1/(o/c + 1))·c`，`c = 0.35·屏高`。o 小的时候跟手（导数 1），越拉越钝，拉到天荒地老也只超出约 1/3 屏 |
| 松手时已越界 | 立刻**回弹**（不甩动），初速度取释放速度 ×0.6 |
| 甩动中撞到边界 | 不再 `stop()`，把余速交给回弹弹簧（先越出一点再弹回） |

回弹是欠阻尼弹簧：`a = −260·位移 − 26·速度`，阻尼比 ζ ≈ 0.81（轻微过冲一次，像 iOS）。

**真机量化**（顶部边界，慢速拖动 3000ms）：
| 时刻 | 页面顶边 y |
|---|---|
| 拖动中（手指仍按着，拉了约 1000px） | **492**（越界 242px ≈ 24%，与橡胶曲线吻合） |
| 松手 1.2s 后 | **250**（精确回到边界，无残留） |

## 4. UI 设计升级（第一版）

方向：**灵动现代简约** —— 更圆的外形、发丝线分层、极浅阴影、短促的按压反馈。
参考：ColorOS 的"圆角 + 呼吸感"、iOS 的"入场慢出场快"、M3 的"表面色分层"、微软的"信息密度优先"。

### 4.1 设计令牌（`tokens.dart`）
- 圆角整体放大一档：`10 / 14 / 20 / 28`（sm/md/lg/xl）；
- 动效：`instant 90 / fast 150 / base 220 / slow 340`（**按压缩短到 90ms**，入场 220、退场 150）；
- 三条曲线：`curveStandard`（减速）、`curveEmphasized`（M3 emphasized）、`curveExit`（加速离场）；
- 纪律写进注释：**入场慢、出场快；直接反馈必须快；位移一律减速曲线**。

### 4.2 主题（`app_theme.dart`）
| 改动 | 为什么 |
|---|---|
| `splashFactory: NoSplash` + `highlightColor: transparent` | **去掉水波纹**：笔尖点按钮时波纹会盖住笔迹、显得脏；反馈改成"元素自己缩一下" |
| 页面转场换成**淡入 + 2% 上移**（自定义 `PageTransitionsBuilder`） | 同一个应用内的视图切换，横向推拉太重；淡入更安静（iOS sheet 感 / ColorOS 轻量切换） |
| AppBar：`toolbarHeight 60`、`scrolledUnderElevation 0`、`surfaceTintColor: transparent` | 顶栏是"容器"不是"盖子"，靠发丝线分层 |
| 卡片两套主题统一：`surfaceContainerLow` + 发丝描边 + 圆角 20 + 零投影 | 原来"暗色无阴影/浅色有阴影"两套逻辑，会让暗色显得更平 |
| chip / NavigationRail / NavigationBar 主题：胶囊指示器、统一字重 | 导航指示器是这套语言里最"灵动"的一处 |

### 4.3 按压微动画（新 `ui/widgets/pressable.dart`）
按下：缩放 `0.97`（卡片用 0.985）+ 透明度 0.86，**90ms**；松开：回弹 `150ms`（`curveEmphasized`）；
可选轻震（`selectionClick`，失败静默）。已应用到：书架卡片、文件夹 chip、笔刷工具按钮。
