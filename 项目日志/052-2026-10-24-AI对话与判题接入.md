## 1. 接手时的缺口

上一个 Agent 已经把「问 AI」的前端架子铺好：
`QuestionAiPayload`（图片权威 + 机器文本来源）、`AiChatPanel`（题目信息/附件/预置提问）、
`LlmClient` 接口、`GradingController`、`AnswerNote.source='ai'`。缺的是整条竖线：

```text
配置入口 → 真客户端 → 提示词/解析 → 流式 UI → 答案落盘 → 判题落盘
```

本轮把这条线补齐，并顺手修了两个真机才能看见的缺陷（§8）。

## 2. 配置：不填也能用，填了立刻生效

- `domain/ai/llm_config.dart`：端点/Key/模型/传图开关/超时；端点自动补 `/chat/completions`；
  `validationError()` 是唯一校验口径；Key 只以 `••••末4位` 回显。
- `infra/ai/llm_config_store.dart`：`setting` 表 `llm.base_url` / `llm.api_key` / `llm.model` /
  `llm.allow_images` / `llm.timeout_seconds`。**没有加数据库版本**。
- `ui/settings/ai_settings_sheet.dart`：设置页与问 AI 面板共用同一弹层。
  - 三个预设（DeepSeek / OpenAI / 通义千问）+ 自定义；
  - Key 输入框永远留空，占位符提示「已保存 ••••abcd（留空=不修改）」；
  - 30/60/120 秒超时；传图开关默认**开**（本产品题面图片是权威来源）；
  - 「测试连接」用当前表单值发 8 token 请求，不先落库；失败按 401/429/网络/5xx 给不同文案；
  - 「清除」二次确认，删掉五个键。
- 设置页「AI 分析」从置灰的 T6.1 变成真入口，副标题显示「已配置 · 模型 · ••••」。

> Key 当前存本机 `setting` 表（App 私有目录，不进日志/导出/上报）。这是零新依赖的取舍；
> 换 `flutter_secure_storage` 时只改 `LlmConfigStore` 的两个方法，调用方不动。

## 3. 客户端：一个薄封装，失败可分类

`infra/ai/openai_client.dart` + `openai_protocol.dart`：

- 用 `dart:io HttpClient`，不引 `package:http`/`dio`：SSE 要按行读、边收边吐，超时/取消在自己手里。
- SSE 按行缓冲，能处理「事件被拆成多个 TCP 包」「多行 data」「`: ping` 注释」「`data: [DONE]`」；
  兼容部分中转无视 `stream=true` 直接回整段 JSON。
- 图片挂在**第一条 user 消息**上，历史再多也不会重复带图；一次请求最多 4 张（题面+作答+2 张补充）。
- 错误分类：`notConfigured / auth / rateLimited / network / server / timeout / badResponse / unsupportedImage`；
  401/403 不重试，429 给「稍后再试」，超时保留已收内容。
- `healthCheck()` 只给设置页用；`testConnection()` 在 app 层返回可读原因与耗时。

提示词在 `domain/ai/prompts.dart`，三条硬口径：

1. 有图时声明「图片权威、机器文本仅辅助」；**只发文本时换成另一套声明**，不让模型以为看见了图；
2. 讲题不判分、不打分、不说「扣分/不得分」；
3. 公式统一 `$…$` / `$$…$$`，只允许 KaTeX 常用子集。

## 4. 对话面板：把「能聊」做成「敢用」

`ui/panel/ai_chat_panel.dart` 重写：

- **进入即准备**：打开前渲染题面/作答 PNG（长边 ≤1024），面板里直接看到「AI 会看到哪一块」；可单独移除。
- **流式**：80ms 节流，不逐 token 重建整棵树；停止后保留半截并标「已停止生成」。
- **失败不装死**：保留已收内容 + 错误气泡 + 「重试」（重试不重复插入用户气泡）。
- **快捷动作**：讲这道题 / 先做一遍 / 判我的作答；「判我的作答」在没有作答时置灰并给 tooltip。
- **相册附图**：`FilePicker.pickFiles(type: FileType.image)` → `readAsBytes()` → 等比压到 1024 →
  缩略图 + 「将发送 N/4 张图」；最多 4 张。图片只随当前发送，不落盘（见 §10）。
- **历史**：每题 `layout/ai_chat.v1.json`；打开时自动滚到最新；错误气泡不落盘；每题最多 60 轮。
- **其它**：复制、清空对话（二次确认）、未配置时的「去配置」空态、窄面板/深色不溢出。
- 入口：题目面板选中题后新增第三颗按钮「问 AI」（之前只藏在 level>1 的「答题情况」卡里，
  level=1 的大题根本进不去）；「答题情况」卡的 AI 入口保留。

## 5. AI 补答案：单独一层，重切不覆盖

- 落点 `layout/answers_ai.v1.json`，源码 `AnswerNote(source:'ai')`；
  与 `answers.v1.json`（PDF 自动抽取、可重抽）**分开**。
- `regionSetProvider` 读的时候 `base.mergeMissing(ai)`：PDF 有答案就以 PDF 为准，AI 只补缺。
- 题目面板答案卡：来源徽标「AI」、正文走 `MathText` 排版、底部明确写「AI 补的答案，请自检；未做判题。」。
- 对话里同时给「参考答案（AI 补）」卡片和「已写入参考答案（AI 来源）」状态。

## 6. AI 判题：结论与来源一起落

- `GradeSource` 增加 `ai`；`QuestionGrade.note` 存模型给的理由。
- `GradingController.applyAi(questionId, verdict, note)`：
  - 已手改（manual）→ 返回 false，不覆盖；面板显示「未覆盖手改」；
  - 否则写 `source=ai`，可被三色手改覆盖。
- `applyAuto` 从「只跳过 manual」改为「跳过所有非 auto」：一键改卷不会把刚花 token 判好的主观题打回 pending。
- 面板里的结果卡：绿/黄/红三色 + 「AI 判：对/错/拿不准」+ 理由 +「已记入判题 / 未覆盖手改」。
- 本轮只做**单题** AI 判题；批量待下一轮。

## 7. 公式：先切分，再排版，失败给源码

- `domain/markup/math_segmenter.dart`：`$$…$$` / `$…$` / `\(…\)` / `\[…\]`；`\$` 字面量；
  代码围栏与行内代码不解析；**未闭合定界符余下全文当文本**（流式安全）。
- `ui/widgets/math/math_text.dart`：`MathText` 混排；行内 `WidgetSpan` 居中，行间独占一行、超宽自动缩小；
  `Math.tex` 失败回退源码，不抛异常。
- 新增依赖 `flutter_math_fork 0.7.4`（白名单内、精确版本；APK profile 67.3→76.4MB）。

## 8. 真机踩坑（都修了）

1. **旧气泡的公式会「消失」**：`ShqMathView` 原先把 `Math` Widget 实例做 LRU 缓存；同一条公式
   同时出现在两条消息里时，先出现的那条在下次 rebuild 后停止绘制公式（文字还在、公式位置空白）。
   修法：**不缓存 Widget 实例**；聊天气泡数量少，重新解析的成本远低于可见缺陷。要缓存应缓存 AST。
2. **打开长对话停在开头**：历史加载后没有滚到底。修法：`initState` 帧后 `_scrollToEnd(force:true)`。
3. **file_picker 13 的 `PlatformFile` 没有 `bytes` 字段**：改用 `await file.readAsBytes()`。
4. **release 没有网络权限 + 明文 HTTP 被拦**：`AndroidManifest` 加 `INTERNET` 与
   `usesCleartextTraffic="true"`（用户可填局域网自建端点；安全取舍见 §10）。
5. **`question_order` 的 dispose 竞态**：`flush` 不清 dirty，dispose 又异步写一次；测试临时目录先删，
   于是 PathNotFound。修法：`flush` 写前清 dirty；测试 dispose 前显式 await flush。
6. `adb shell input text "a b"` 只输入第一个词（shell 分词），不是 App 的问题；真机验证用无空格文本。

## 11. 未决 / 风险

| 项 | 说明 / 倾向 |
|---|---|
| 真实厂商端点 | **未验证**。用户填 Key 后需验：是否支持 `image_url` 多模态、是否接受 `temperature`、JSON 是否稳定。 |
| Key 存储 | 目前 `setting` 表明文（App 私有目录）。倾向下一轮换 `flutter_secure_storage` 并做旧键迁移。 |
| 明文 HTTP | `usesCleartextTraffic=true` 是为局域网自建端点；若只允许 HTTPS 可去掉，但会牺牲本地调试。 |
| 用户附图持久化 | 相册图只随当前发送；重开后只恢复文字。需要落 `layout/ai_images/` 并在打开时重载。 |
| AI 判题时效 | 改了作答后 AI 结论不会自动失效；用户可重判或手改。是否在笔迹 revision 变化时清 AI 结论，待拍板。 |
| 批量 AI 判题 | 未做。当前逐题入口；批量要考虑成本/并发/失败重试。 |
| 对话附件计费 | 每条消息都重带题面（1 张）+ 作答（1 张）；这是为了模型每轮都能看到题面，成本可接受但要写进产品说明。 |
