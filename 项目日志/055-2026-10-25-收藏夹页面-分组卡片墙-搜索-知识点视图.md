## 1. 设计口径（用户 2026-10-25 确认）

- 默认形态 = **按更新时间倒序的「按卷分组」卡片墙**；组头 = 卷名 + 题数，组内/组间都按最近更新倒序。
- 卡片 = 题面预览 + 来源(卷名) + 知识点/题型标签 + 判定徽标；**题面裁切不统一时统一压进固定卡片区域**（`BoxFit.cover`）。
- 知识点 = 自由标签；**一题多标签时在每个标签组都出现**（检索不漏），无标签归「未归纳」（固定排最后）。
- 呈现一致性：对齐书架大图卡（`Card` + `Pressable(0.985)` + 缩略图 `Expanded` + 元信息）。

## 2. 实现要点

### 2.1 分组/检索纯函数（`domain/model/favorite_group.dart`，可单测）

- `groupByWorkbook` / `groupByKnowledge` 都在**已按 updatedAt 倒序**的输入上遍历：
  首次遇到某组 = 它最新那道题 → **组序 = 首次出现顺序**，组内保持倒序；用 `_take` 摘桶防重复产出。
- `searchFavorites`：题号/卷名/题干/知识点不区分大小写匹配。
- 组数据形状 `FavoriteGroup(key, title, items)`；未归纳键 `kUnfiledGroupKey`。

### 2.2 卡片（`ui/favorites/favorite_card.dart`）

- 题面图 `Image.file(stem.png, fit: cover)`；**迁移来的老收藏无图 → errorBuilder 兜底显示「第 N 题」占位**（真机验证）。
- 右上角判定徽标 = `GradeDot` + 半透明白底圆（与书架多选勾选圈同语言）。
- 元信息：`第 N 题`（加粗）+ 题型（右侧小字）→ 知识点胶囊（≤2 枚，`secondaryContainer`）→ 卷名（`sourceDeleted` 时红字加「原卷已删」）。
- 无标签时显示灰色「未归纳」，保证有/无标签的卡片高度一致（书架同款经验：**元信息行高固定才不会"卡片没对齐"**）。

### 2.3 页面（`ui/favorites/favorites_page.dart` 重写）

- 顶部搜索框（pill 圆角填充底）+ `SegmentedButton`（按试卷 / 按知识点）；过滤后为空给「没有匹配的收藏」空态。
- 分组渲染 = `CustomScrollView`：每组一个 `SliverToBoxAdapter`（组头）+ `SliverPadding(SliverGrid)`；
  网格 `maxCrossAxisExtent: 220 / childAspectRatio: 0.78`。
- 长按 → `showModalBottomSheet`（显式 `backgroundColor` + 顶部圆角，老坑）：编辑知识点 / 加入组卷 / 取消收藏。
- 编辑知识点 = `AlertDialog` + `TextField`（`KnowledgeTags.parse` 归一），保存走 `FavoriteStore.updateKnowledgeTags`（新方法）→ `invalidate(favoritesProvider)`。
