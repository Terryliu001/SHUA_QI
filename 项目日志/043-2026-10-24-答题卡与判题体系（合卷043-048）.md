## 一、入口与总流程

### 1.1 顶栏三入口常驻（043）

**结论**：题目区域、缩略图、答题卡三入口从「更多」搬出来常驻顶栏，窄屏才折叠。

### 1.2 答题卡流程（043 → 048 定稿）

**第一步：切题确认**（`ui/panel/answer_sheet_prep.dart`）

## 二、作答框与数据契约（043 / 044 / 045）

### 2.1 `layout/answer_sheet.v1.json`

**结论**：一题一条，键全小写下划线，版本号 1。

```json
{ "version": 1, "answers": [ { "question_id": "...", "page": 3, "rect": {},
  "region_source": "auto|manual", "ocr_text": "...", "ocr_conf": 0.82,
  "ocr_engine": "ink_mlkit", "crop_path": "...", "updated_at": 0, "ocr_at": 0 } ] }
```

- 类 `AnswerSheetEntry`（`domain/model/answer_sheet.dart`）。字段 ↔ 键：
  `questionId→question_id`、`pageIndex→page`、`regionSource→region_source`、
  `ocrText→ocr_text`、`ocrConfidence→ocr_conf`、`ocrEngine→ocr_engine`、
  `cropPath→crop_path`、`updatedAt→updated_at`、`ocrAt→ocr_at`；
  `toJson()` = `{version:1, answers:[...]}`；
  路径 `VaultPaths.layoutAnswerSheet`（`infra/vault/paths.dart` 是路径唯一入口）。

### 2.2 建框规则：只给小题，默认 = 最后一段整题区域

**结论**：作答框只对 `question.level > 1` 的小题自动建；
默认框取 `slices.last`（最后一段整题区域），不是整页、也不是第一块。

- `defaultFor(bundle)` 取 `bundle.slices.last`，`regionSource = auto`。
- 拖/缩放后 `updateRect` 默认写 `source = manual`；
  手改框 UI 上**统一中性色**，不再用主题色（避免与题目框撞色）。
- `reset()` 保留 `ocr/crop` 只清框；`prune(keepQuestionIds)` 清幽灵；
  `_persist` 串行队列落盘。

### 2.3 作答框与题目框互斥编辑

**结论**：同一时间只能编辑一类框，靠一个开关切换。

- `RegionMark.isAnswer`：true 时画紫色**虚线**作答框
  （level=1 大题虚线 / level=2 小题另一套）。
- `RegionOverlayConfig.answerEditing == true`：作答框可点选/拖动/缩放，
  题目框锁定；关掉相反。面板「显示作答情况」打开 = 进入作答框编辑。
- **坑（语义陷阱）**：`RegionMark.grade/confidence` 来自
  `RegionGrade.of(question.confidence)`，那是**切题置信度，不是判题对错**。
  048 起判题单独走 `grading.v1.json`（§六），别再往 `RegionGrade` 塞判题结果。

### 2.4 作答原图

- `VaultPaths.answerCrop(id)` = `layout/answer_crops/<safeId>.png`；
  `renderAnswerCropPng`：PDF 原页 + 页笔迹裁切，宽 clamp 320–1024、高 ≤1600，
  导出 `darkPaper: false`（白底）；`updateCrop` 只记路径不存字节。

## 三、答题卡画布与纸张（044 / 046 / 048；049 覆盖张数）

### 3.1 每题独立 SIF，多张生效

**结论**：一题一份 SIF；**044 初版忽略 `pageIndex`，048 起真正生效**，
文件名带张号。

- `VaultPaths.answerInk(workbookId, sessionId, questionId, [paperIndex = 0])`：
  `paperIndex <= 0 ? '<safeId>.sif' : '<safeId>_p<paperIndex>.sif'`，
  目录 `sessions/<sid>/answers`。
- `AnswerInkStore`（`infra/ink/answer_ink_store.dart`）：`load` 按
  `InkPageKey(sessionId, pageIndex, workbookId:)` 定位，主文件坏/缺读 `.bak`；
  `_fit()` 在 `SifCodec.readPageSize` 与当前纸张不一致时调 `scaleInkDoc`
  等比搬移（**换纸张不丢笔迹**）；`save` 用当前纸张尺寸编码，优先 `Isolate.run`；
  静态 `_paperCache` + `invalidatePaperCache(workbookId)`。
- 路由：`state/ink_providers.dart` 的 `kAnswerInkPrefix = 'ans'`，
  `answerInkSessionId(sid, qid) => 'ans:<sid>:<qid>'`，
  `inkStoreForKeyProvider` 分流到 `AnswerInkStore`；
  writer 500ms 防抖，`flushSave()` 供切题/退出落盘。

### 3.2 虚拟画布尺寸与缩放

**结论**：虚拟画布固定 1000×600 pt（5:3）；缩放 0.8×–4×，按钮每档 1.25×。

- `AnswerCanvas.widthPt = 1000`、`heightPt = 600`、`aspect = 1000/600`
  （044 记的 1000×600 pt 当前仍成立）。
- `InteractiveViewer(minScale: 0.8, maxScale: 4)`，
  `transformationController: _zoom`；`_zoomBy(1.25)` / `_zoomBy(1/1.25)`，
  复位 `Matrix4.identity()`。
- **手形/书写**：`handTool`（默认 `true`，来自 `ReaderPrefs.defaults`）
  传成 `panMode`——**手形模式手指拖动只平移不落墨**，切书写模式才落笔；
  049 起默认手势模式。
- 坑：046 前不能缩放，长答题卡（尤其 A4 横向）字太小写不进；
  加缩放就必须同时给「不落墨的拖动」，否则一平移就画满线。

### 3.3 题面浮层可收起（046）

- `_questionCollapsed` + `onToggleQuestion` 控制收起/展开，收起后整屏给书写区
  （坑：题面常驻占位时小屏书写区只剩不到一半）。

### 3.4 纸张 `layout/answer_paper.v1.json`（048；049 覆盖张数）

**结论**：纸张是**每题可覆盖**的配置；SIF 坐标就是纸张 pt，换尺寸按比例搬。

| 尺寸 | 纵向 (pt) | 横向 (pt) |
|---|---|---|
| compact | 600 × 1000 | 1000 × 600 |
| a4 | 595 × 842 | 842 × 595 |
| b5 | 499 × 709 | 709 × 499 |

- `orientation = landscape` 时 `widthPt = base.height`、`heightPt = base.width`。
- `static const int maxPages = 9;`（**049 覆盖：048 原记 1–4**）；
  `pages` 在 `fromJson`/`copyWith` 里 `clamp(1, maxPages)`。
- 数据 `AnswerPaperData` = `{version:1, default, by_question}`；
  `forQuestion(qid)` 取覆盖否则回落 default；键 `size/orientation/pages/rule`；
  `AnswerPaperRule` 五种（枚举名以 `answer_paper.dart` 为准）；
  存储 `AnswerPaperStore` → `LayoutStore`。
- **049 覆盖**：张数**不再做成设置**。书写区左右两侧翻页键 `onPaperStep(±1)`，
  **最后一页右键变「＋」**（`onAddPaper`）直接加一张，上限 9 但界面不显示数字；
  `answer_paper_sheet.dart` 的 `_Group` 只剩「尺寸 / 方向 / 纸样式」，
  底部 `SwitchListTile`「应用到本卷所有题目」→ `AnswerPaperChange(paper, applyAll)`。

## 四、手写 OCR（045）

**结论**：纯本地、笔画级（引擎 A），行聚类后逐行喂 ML Kit Digital Ink；
结果写回 `answer_sheet.v1.json`。

- 引擎 `infra/ocr/mlkit_ink_engine.dart`，`name = 'ink_mlkit'`，
  依赖 `google_mlkit_digital_ink_recognition` 0.16.1。
- `warmUp()` 按 `[language('zh-Hans'), 'en-US']` 依次
  `isModelDownloaded/downloadModel`，**失败返回 `false` 不抛异常**。
- `recognizeStrokes`：空笔画/纯荧光笔 → `conf=1`；`clusterInkLines` 行聚类
  → 每行转 `Ink` → `recognize`；>300 字标 `truncated`，置信按字符数加权；
  模型不可用 → `conf = 0`。`recognizeImage` 返回空——**引擎 B 未接**。
- 置信 `1/(1+exp(score))`，`clamp(0.05, 0.99)`，非有限 → 0.5；
  ML Kit 原始分**越负越好**，sigmoid 翻正。
- 回写 `updateOcr` 同时写 `ocrAt = now`；
  `ocrStale => hasText && ocrAt > 0 && updatedAt > ocrAt`（框改了要重识别）。
- 面板侧 `_recognizePanelAnswer`：先 `_loadAnswerInkPages(bundle)`；
  **无答题卡笔迹时回落 PDF 页内** `_strokesInRect(pageDoc, entry.rect)`。
- 坑：整页一次喂 ML Kit 会多行串成一行，识别率明显下降；
  按行聚类后中文手写可用，代价是行聚类要调参，斜着写的行仍串行。

## 六、判题与改卷（048；049 / 051 工具栏上移）

### 6.1 契约 `layout/grading.v1.json`

**结论**：判题与切题置信度彻底分开，单独文件、单独模型。

```json
{ "version": 1, "grades": [ { "question_id": "...", "verdict": "none|correct|wrong|pending",
  "source": "auto|manual", "at": 0, "note": "" } ] }
```

- `domain/model/grading.dart`：
  `enum AnswerVerdict { none, correct, wrong, pending }`、
  `enum GradeSource { auto, manual }`；
  `QuestionGrade` 键 `question_id/verdict/source/at/note`。
- `GradingData.countsOf(ids)` → `VerdictCounts(correct/wrong/pending/none)`；
  `retain(keep)` 清幽灵。
- **一键改卷永不覆盖手改**：`GradingController.applyAuto` 里
  `if (existing != null && existing.manual) continue;`——只覆盖 `auto`；
  `setManual` 写 `source = manual`；`prune/flush` + 串行 `_persist`。

### 6.2 本地规则判客观题

**结论**：客观题本地判；判不了/主观题一律 `pending` 等 AI——**不猜**。

- `domain/region/grading_rules.dart`（纯函数，17 例单测）：
  `normalizeAnswerText` 全角→半角、`×→x`、`÷→/`、去空白、
  去前缀 `答案:/答:/解:`、去尾标点、转小写；
  `looksSubjective(ref)` 长度 > 20 或含 `证明/略/同上/见图/略述` → true；
  `optionLettersOf` 认 `^[A-D]{1,4}$` 纯字母串或独立字母。
- `judgeObjective`：空 → `none`；ref 单字母 a–d → 比选项集合；
  两边成数 → 容差 `1e-6 * max(1, |ref|)`；
  相等或 `ref.length >= 2 && got.contains(ref)` → correct；
  `looksSubjective` → `null`（落 pending）；否则 wrong。
- 调用：`_judgeOne` 用
  `judgeObjective(answer: _answerEntryOf(bundle).ocrText, reference: note.text)`，
  `verdict ?? pending`；`_gradeAll` 调 `applyAuto(verdicts)` 并提示
  `改卷完成：对 N · 待判 N · 错 N · 未判 N`。

### 6.3 交互：三色点 + 工具栏上移

- `_QuestionRow` 带 `grade` 三色点，`onGrade` 菜单手改
  （对/错/待判/清除）走 `setManual`。
- **049/051 覆盖**：判题/改卷工具栏**上移到面板顶部常驻**（`_ToolsBar`），
  不再只在选中后出现；同时去掉「问 AI」（答题情况卡已有入口）。
- 底部仍有 `_GradeBar`（对/待判/错/未判统计条）+
  `_Actions` 5 图标（新增/撤销/重做/复原/重切）。

### 6.4 多选批量 / 加题

- `RegionPanelBatch.favorite` → `FavoriteStore(...).addAll`，
  **真落 `layout/favorites.v1.json`**（`{version:1, question_ids}`，
  合并后排序去重）；`checkAnswer` → `applyAuto`（同样跳过 manual）。
- 选中虚线作答框（或题目框）时给「加题」，
  由 `AddQuestionCorrection` 提升为正式题目；
  配 `questionDeltaOf` 统计净增（§7.5）。

## 七、题目面板（044 / 047 / 048；051 定层级）

### 7.1 面板层级（051 定稿）

**结论**：顶栏 → 常驻工具栏 → 批量条 → 选中块 → 列表 → 统计条 → 5 图标。

`ui/panel/region_panel.dart` 的 `build` 顺序：`_Header`
（total/delta/showAnswers/onSave/onClose）→ `Divider` →
`_ToolsBar`（多选/改卷，**常驻**，条件 `onGradeAll != null ||
onToggleMultiSelect != null`；理由：题面预览只是选中后的上下文，
压在上面会把工具栏挤下去）→ `if (multiSelecting) _BatchBar`
（已选 N · 收藏 · 对答案 · 完成）→ `if (selected != null && !multiSelecting)`
「题面预览 + 收藏/对答案」**同级一块** → `ReorderableListView.builder`
（`buildDefaultDragHandles: false`，行 `GlobalKey _rowKeyFor`，
`dragHandle: ReorderableDragStartListener`，**多选时为 null** 避免与勾选冲突）
→ `Divider` → `if (counts != null) _GradeBar` → `Divider` → `_Actions` 5 图标。

### 7.2 手动排序 `layout/question_order.v1.json`（044）

- 落盘 `{version:1, order:[...]}`，文件 `VaultPaths.layoutQuestionOrder`。
- `apply(questions)` 按 `order` 里 rank 排序，
  **缺失 rank 视为 `1 << 20`**（排最后）。
- `move(current, oldIndex, newIndex)` 目标 `clamp(0, len-1)`；
  **注释明确不要 `newIndex--`**——`onReorderItem` 已扣过偏移，再减错位一格。
- `reset()` 回自动序、`prune()` 清幽灵；入口为长按行 → `_openOrderMenu`。

### 7.3 拖影夹紧（047）

**结论**：框架默认拖影完全跟手，能拖到列表外（甚至状态栏上）；
改成「列表视口 + 相对位移」夹紧。

- `_proxyClampDelta()`：
  `desiredTop = _dragStartTop + (_pointerY - _dragStartPointerY)`，
  夹到 `[listTop, listBottom - _dragRowHeight]`。
- `proxyDecorator` 必须**自己补 `Material`**（`elevation: 6`、
  `surfaceContainerHigh`、`ShqRadius.md`、`clipBehavior: antiAlias`），
  否则行内 `InkWell` 报 "No Material widget found"。

### 7.4 面板可拖宽（047；049 改绝对位移）

**结论**：一条全局宽度，题目区域与 AI 面板共用；拖动中阅读区不让位。

- `domain/reader/panel_metrics.dart`（纯函数）：`minWidth = 320`、
  `narrowFraction = 0.42`、`narrowBreakpoint = 760`、`maxScreenFraction = 0.5`；
  `minFor = screen < 760 ? screen*0.42 : 320`、`maxFor = screen*0.5`；
  `clampWidth` 在 `max <= min` 时返回 min（超窄屏兜底）。
- 持久化 `AppSettingKeys.panelWidth = 'panel.width'`
  （**日志原写 `setting.panel.width`，实际键名是 `panel.width`**），
  走 `SettingDao` 存整数字符串 dp；`PanelWidthController` 是
  `Notifier<double?>`，`preview()` 只改内存、`commit()` 异步落盘。
- **坑 + 修法（047 → 049）**：现象拖动不跟手、宽度跳；根因是旧实现每帧
  「累加增量 + clamp」，clamp 丢掉的部分补不回来；修法改**绝对位移**——
  `panel_resize_handle.dart` 回调「自起点以来的总变宽量」
  `onResize(_startX - details.globalPosition.dx)`，
  `_onPanelResize` 用 `_dragStartPanelWidth + totalGrow` 再 clamp。
- **拖动中阅读区不让位**：`_panelInset` 拖动期间返回**已存储宽度**，
  松手 `_onPanelResizeEnd` 才 `commit` 并重排；
  否则 `PageLayer` 每帧重新取位图，拖动直接卡死。
- 把手 `Positioned(right: _panelWidth(context) - 14, width: 28)`，命中区 28dp。

### 7.5 净题数变化提示（047）

- `domain/region/correction.dart` 的 `questionDeltaOf(log)`：
  Add/Split +1，Delete/Merge −1，移动/缩放/跨页/改题号/锁定 0。
- 坑：早先按「操作数」计数，拖一下框也 +1，数字虚高；
  改净题数后 `_Header` 只在真的多/少题时显示，保存后收掉。

### 8.1 `ui/widgets/image_viewer.dart`

- `showImageViewer(context, title, aspectRatio, builder, actions)`：
  `showGeneralDialog` + `FadeTransition` + `ScaleTransition(0.96 → 1)`；

  （body 内自绘标题行 + 关闭键 + 缩放百分比）。
- `InteractiveViewer(minScale: 1, maxScale: 5, panEnabled: _scale > 1.01,
  boundaryMargin: 48)`——未放大时禁平移；整层与图片各挂 `onTap: maybePop`。
- `_fitted` 按**真实宽高比**：`maxWidth/maxHeight > aspect` 时高 = `maxHeight`、
  宽 = `height*aspect`（长图限高居中）；否则宽占满、高 = `width/aspect`。
- `showImageActions`：右侧浮窗宽 212，与按点垂直对齐；执行后显示
  「处理中 → 结果」，1.4s 自动收起。
- 坑：早期直接把图 `contain` 塞对话框，长图压扁、宽图两侧空白，
  双指缩放还与页面手势打架；改为按 aspect 手算尺寸 + 独立 `InteractiveViewer`。

## 遗留与未决

1. **AI 判题未接模型**：`pending` 是给 AI 留的落点；`judgeObjective` 遇主观题
   返回 `null` → 落 `pending`。目前无模型调用，AI 补答案/判题都是占位入口。
2. **公式与图形识别缺失**：`recognizeImage` 返回空（引擎 B 未接），
   含公式/图形/表格的作答识别为空，只能人工看答题情况卡。
3. **行聚类边界**：`clusterInkLines` 对斜写、跨行连笔、行距不均仍串行/断行，
   识别率无量化指标，缺真机样本回归。
4. **OCR 无纠偏 UI**：`ocrStale` 只打「待重识别」标签，不能就地改识别文本。
5. **面板宽度只有全局一条**：`panel.width` 题目区域与 AI 面板共用；
   `clampWidth` 在 `max <= min` 超窄屏返回 min，此时拖不动（预期兜底）。
6. **测试环境既有失败（非本轮回归）**：宿主机 `tool/run_tests.sh` 因摘掉 pdfrx，
   5 个用例编译失败——`ai_chat_panel`、`answer_ink_store`、
   `bookshelf_grid_layout`、`ink_edit`、`page_layer`。
7. **未核实项**：044「手改框统一中性色」色值未逐一核对（以
   `region_overlay.dart` 当前取色为准）；`AnswerPaperRule` 枚举名以
   `domain/answer/answer_paper.dart` 为准。
