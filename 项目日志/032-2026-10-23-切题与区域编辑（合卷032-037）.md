## 1. 管线总览

**结论**：切题是「**分栏 → 行 → 题号**」的纯函数链；扫描件与文本层**共用同一套切分引擎**；自动结果永远只读，用户修改永远走覆盖层。

```text
PDF ├─ 有文本层 → L0 抽取（text.json，只存行）→ L1 splitQuestions
    └─ runs=0   → L2 scan（渲染 1400px 长边 → 行级题号字形 → 复用 L1 切分）
                   └─ 行级 <2 段 → 块级兜底 layout_blocks
      ↓ regions.v1.json（只读，带 cutter 代次）+ answers.v1.json
      ↓ 套用 corrections.json（先落盘再重算）
      question / question_region（一个事务整卷替换）+ layout_status
```

- **顺序不能反**（`page_layout.dart`）：`detectColumns → groupByColumn → 每栏各自 clusterLines → 打栏号 → dropMargins`。先聚行后分栏会把双栏页拼成一条横跨整页的行（单测抓到：8 行并成 4 行）。
- **L2 复用 L1**：给 `TextLine` 加 `forcedMark`，`split.dart` 里题号来源改为 `forcedMark ?? matchQuestionMark(text)`——一行差别。跨页两段、双栏不串栏、容器不占区域、置信度公式全部共享（重写必然再踩一遍）。
- 入口 `RegionBuilder.run()`（`region_builder.dart:85`），可重入可取消；取消时不写库，已抽的文本层落盘复用。

**坑**：触发 L2 用 **`markCount == 0`** 而非 `regionCount == 0`——后者为 0 而前者 >0 说明"题号认出来了、只是全被判成容器"，不该被切块覆盖；行级要求 `regionCount >= 2` 才采用（整页图片/竖排/特殊编号时"8 块里 6 块是题"仍比 0 个框强）。

## 2. L0 文本层：只落"行"

**结论**：`layout/text.json` 只存聚行结果，不存 pdfrx 碎片（`runs`）；可删可重建。

```json
{"version":1,"pages":[{"index":0,"w":595.32,"h":841.92,"runs":581,
 "lines":[{"t":"1.设𝑓(𝑥)={…","x":79.5,"y":103.3,"w":218.4,"h":29.2,"fs":10.3,"c":0}]}]}
```

pdfrx 给的是 ~490 个/页的碎片（`12.` 拆成 `1`/`2`/`.`、夹零宽 `\n`）；存碎片则阈值一调旧文件就得重读。聚行结果本身就是"一句话 + 位置"，正是第 4 周喂 AI 的形态。

**关键**：行字号取片段高度的**下四分位**（`text_line.dart:217`），不是中位数——pdfium 把多行公式报成一个文本对象，`bounds.height` 等于整个对象跨度，实测 `设𝑓(𝑥)={…}` 那行片段高 **29.1pt** 而正文只有 11.6pt。

**证据**：体积 159KB → **10.7KB**（真卷 4 页）；重抽 6–29ms/卷，比读大文件还快；逐页抽取之间让一帧，20 页不卡 UI。

## 3. L1 规则切题（文本层）

### 3.1 分栏：1pt 箱被文字行覆盖率 ≥15%

把 x 切成 1pt 箱，统计每箱被**多少比例的文字行**覆盖，**≥15% 算"有字"**（`_blockedRowShare = 0.15`，`columns.dart:42`），再找居中的连续无字带作栏间距。

- 试过**像素全页并集**：双栏卷一行居中标题横跨栏间距 → 判成单栏，废。
- 试过"同一行两侧都有字就否掉"：真双栏两栏共用基线，同高两侧有字是常态 → 双栏被判单栏，废。
- 现行 ≥15%：居中标题只占 2–3 行（<5%）不影响；图注挖空占 30–40% 的行仍算"有字"。

**硬规则**：下一题若在同一页的另一栏，**"另一栏的栏顶"不能当本题下界**——双栏页第二栏从页面顶端开始，用它当截断线会让第一栏最后一题的下界跑到上界之上、整段被丢（实测双栏卷第 4 题直接没有框）。现取"本栏栏底"。

扫描件与文本层共用 `detectColumnsFromRects`（`columns.dart:52`），避免两套阈值各自漂移。

### 3.2 层级：样式优先，字号兜底

**结论**：规格里"字号跳变 ≥1.15 倍即大题"在数学卷上是**坏信号**（见 §2 公式撑高 2–3 倍），只在没别的信号时用，且扫描件完全不用。

顺序（`leveling.dart`）：① 中文数字/罗马数字/`【例 x】` → 大题；② 同卷既有 `1.` 又有 `（1）` → 前者大题；③ 只剩同一种题号才用字号断层；④ 都没有 → 全同级。

- `split.dart:263` 传 `allowFontFallback: !fromOcr`：扫描件行高是像素行段估的，倾斜/上下标/公式让同级差 1.3 倍以上，真机第 1 页第 8 题因此被判成容器、整题没框。
- **`firstChildGap`**（`split.dart:277`）：大题与第一道小题之间还有正文（材料）就给它自己的区域，止于第一道小题；`一、单选题` 下面紧接第 1 题（0 行）仍是纯容器。真机 200dpi 卷第 4 页 5 段 → 6 段。
- 大题是否占区域看它到下一个大题之间**有没有小题**；没有（如 `三、（14分）求函数…`）必须占区域，否则整节白切。

### 3.3 置信度与三色

阈值 **0.80 / 0.55**（`greenThreshold`/`yellowThreshold`，`confidence.dart:39`），但**当前不参与画框**（见 §6.2）。

```
conf = 0.45 + 0.20*boundary + 0.15*style + 0.10*order + 0.10*text − 0.20(fromOcr/版面)
```

三条校准（真机数据推翻的）：**负 gap 不算异常**（`ratio < 0 → 1`；含公式的题 gap 实测都是负的，按"间距异常"扣会让好题集体变黄）；**style 分下限 0.4**（字号是近似值，差得远也只扣 0.09，不至于把几何正确的框打成红框；基准是**同层级字号中位数**，相邻比较会让噪声互相放大）；扫描件/版面推断整体 −0.20 → 一律黄框（≈59%），且 `number = null`（不拿猜的序号刷"顺序连续"分）。

### 3.4 含答案 / 解析的卷（仅文本层）

| 形态 | 规则 |
|---|---|
| 文末答案区 | 行文本只匹配 `^(参考答案与解析|参考答案|答案与解析|试题答案|评分标准|答案|解析)`（可带短括号说明）→ 之后不再收题号；最后一题的框**止于标题行**，答案不进题目框。命中后抽成 `AnswerSet` 写 `layout/answers.v1.json`（cutter=5 起落盘） |
| 题内解答步骤 | 行首 `解：/证明：/答：/分析：/解析：` 或 `【答案】` 后，后续 `（1）(2)①` 一律并进当前题，遇到下一个阿拉伯题号再恢复 |

**坑**：标题只认"纯标题"——`答案：B` 若被当成标题，整卷会在第一题的答案处停止切题；它仍留在该题区域内，不丢失。

## 4. L2 扫描件切题（无 OCR）

### 4.1 三级递进与渲染口径

```text
renderGray(长边 1400px) → 一次像素扫描（行墨量/边界 + 每列"有多少行有墨"）
  → 分栏 → 逐栏：行段 → 合并上下标 → 行 → 字高中位数 → 行首字形分类 → ScanLine[]
  → splitScanPages：候选挂 TextLine.forcedMark
  → 复用 splitQuestions(pageLines, fromOcr: true)
  → _relabel：标签=序号、source='layout'、kind='unknown'、stem=''
```

- 缓存 `_scanLineCache`（key=`workbookId|页|1400|WxH`，上限 `_scanCacheLimit = 400` 页，超了整体清空）。每次编辑都整卷重算，扫描件逐页渲染 + 扫像素约 10–15ms/页；同一份 PDF 像素不变，**不需要失效逻辑**。
- **字高从原始行段求，不从合并后的行求**：合并会把"题干 + 下一行"并成 2 倍高的块，中位数被带偏 → 阈值一起放大（第一版 em 从 21px 变 47px，一条题号都没检出）。
- **行距取空白带下四分位**，不取中位数（段落间距远大于行距：5 行的一页中位数 19px，真实行距 5px）。
- 页面四周 **0.8% 裁边**（`borderTrimRatio`）：真机第 1 页右边界一列黑条让整页每行都"有墨"，行距算成 0，44 行并成 1 行。

### 4.2 题号识别：行首连通域字形分类（现行，`scan_tokens.dart`）

**结论**：035 的"短块 + 空白"几何指纹已废，改看**第一个字的连通域形状**，这是当前唯一入口。

```text
行首窗口 max(10, 3.4em) → 8 邻接连通域（先合并重叠碎块）→ 形状分类 → 累加 token
```

| 形态 | 宽/em | 高/em | 墨占 em² | 例子 |
|---|---|---|---|---|
| 窄高块（数字/括号） | 0.06–0.55 | 0.35–0.92 | ≤0.18 | `9` `1` `（` `）` |
| 汉字 | 0.55–1.05 | 0.60–1.00 | 通常 >0.18 | `中` `国` `习` |
| 句中标点 | ≤0.50 | ≤0.32 | 很低 | `.` `、` `,` |
| 横画（中文序号） | ≥0.55 | ≤0.42 | 低 | `一` `二` |

只让**窄高块**或**横画**开头的行进候选；累加 token 直到：小数点/顿号 → 结束（`9.` `12、` → arabic）；右括号 → 结束（`（1）` → paren）；汉字 → 结束（`求` 不进 token）。题号后必须还有 **≥1.2em** 正文（孤零零的编号是页码/装饰）。

**三条硬约束（真机踩出来的）**：① **小数点必须保留**——只有 3×4 像素，旧版按"与行主体重叠 ≥35%"过滤会当噪声丢掉，`9.` 永远认不成"数字 + 小数点"；② **不要把 `13` 合并成一个字**——两个数字之间 3–5px 与汉字笔画同宽，合并后宽高比 >1.05 会判成汉字（真机第 13 题因此消失）；③ **先合并重叠连通域**——同一个 `3` 被扫描噪声拆成 4×5 与 11×20 两块（左边界相同），不合并 token 只有 4px 宽 → 整题消失。

**废弃方案（一句带过）**：035 的 `ScanLineOptions.leadGapFactor`（真值 **0.16**）**已随 036 删除**——汉字笔画本身是断开的（`习` `小` `川` 字内空隙 3–5px，与题号后空格同量级），真机一页 11 道题切出 10 段、其中 3 段是续行、漏 4 道。035 为补救它加的**块宽一致性闸 `_tokenWidthBand`**（0.25em 分桶取众数，区间 `[0.4×mode, 2.3×mode]`）、页首闸、块形突变闸**也一并删除**：误报一多众数本身被污染，真题号一起被误杀（代码注释已写明根因在 `scan_tokens.dart` 修掉）。全角逗号后的自然空白（≈0.5em）曾让 `础上，指出…` 伪装成题号（真机 52 道 vs 实际 44），字形分类后此类误报是否彻底消失**未核实**。

### 4.3 左边距与去噪（`splitScanPages` / `_dominantLeft`）

- **`_dominantLeft` = 最左的"足够大"簇**：行左边界按 1em 容差聚类，先算最大簇人数 `maxCount`，从左往右取第一个成员数 **≥ max(3, 30%×maxCount)** 的簇。
  - 不是"众数"（035 口径，**已改**）：选择题页的选项行（缩进 1.7em）往往比题干行多，按众数选中选项缩进 → 真机第 3 页 9 道题切出 20 段，全是 A/B/C/D。
  - 不是"最左"：真卷第一页常有竖排"考试注意事项"、表格左栏这类更靠左的行 → 真机第 1 页 **0 个框**，33 道题全跑到第 2–4 页。
- **行左右边界只认"有一定高度的墨迹列"**（列内墨点数 ≥ max(2, 行高×8%)）：200dpi 扫描件是 1-bit 传真图带孤立黑点，1px 黑点就能把 `C.` 选项行的左边拉到正文左边（A4 卷第 2 页多 1 段假题）。
- 左边界闸：题号 `left` ≤ 本栏正文左边距 + **1.2em**（`_marginTolerance`）；中文序号标题放宽到 **3.5em** 但必须是短行（`width > 栏宽×0.75` 否掉）；行至少 **2.2em** 墨。1.2 而非 1.0：真扫描卷有 0.3–0.6° 倾斜、左侧 20pt 漂移是常态，而选项缩进 2 字（≈2em）仍被挡在外面。

### 4.4 块级兜底（`layout_blocks.dart`，保留）

行级一条也命中不了时退回纯版面切块。阈值**不能写死绝对 pt**（A4 扫成 200dpi 后页面 1684×2384pt = A4 的 2.8 倍，"固定 pt"只等于行内空白），按**本页行距中位数**自适应：

| 参数 | 当前值 | 作用 |
|---|---|---|
| `separatorFactor` | **1.35**（原为 1.8） | 多宽的空白算"题与题" |
| `minBlockFactor` | 0.9 | 多矮的块直接丢 |
| `mergeShortFactor` | **2.4**（原为 2.2） | 多矮的块算"上一题的尾巴" |
| `mergeGapFactor` | 2.6 | 尾巴与上一题的间距上限 |
| `maxBlocks` | 60 | 整页图兜底 |

**坑**：`mergeGapFactor` 必须 **大于** `separatorFactor`，否则"先切出来再并回去"永不发生（第一版 1.5 < 1.8，合并规则是死代码）；**合并只允许一次**（`lastWasMerged`），否则一串短块级联吃成整页一块。三版实测同一份扫描卷：v1 固定 pt → 91 块（太碎）；v2 占页高比例 → 13 块（8 道题挤一块）；**v3 自适应 → 30 块（A4）/ 35 块（200dpi）**。

### 4.5 算法换代自动重切

`regions.v1.json` 末尾写 `cutter` 代次，**当前 `kCutterVersion = 5`**（`region_builder.dart:337`；032–037 期间依次 2 → 3 → 4，**均已过时**）：1=只有 L1+块级 L2；2=行级几何指纹（035）；3=连通域字形分类 + 去噪 + 左边距取最左可信簇（036）；4=题干按行保留换行 + 数学字符归一化（037）；**5=文末答案区抽到 `answers.v1.json`**。打开卷子时 `region_providers.dart:120` 发现代次落后 → **后台静默重切**，覆盖层按 anchor 重放，用户不丢手改、也不需要知道"重新切题"。

## 5. 区域编辑：`corrections.json` 覆盖层

### 5.1 有序操作列表，先落盘再重算

`corrections.json` 存**有序操作**不存最终矩形；撤销 = 弹掉最后一条再重算；重切 = 把同一串操作重放到新的自动结果上。

```json
{"version":1,"workbook":"06GP…","ops":[
  {"t":"move","id":"06GPG16Y…","key":"2.|0|518","page":0,"dx":0,"dy":-214.05}]}
```

当前 op **10 种**（033 原文写"九种"）：`move`/`resize`/`addSlice`/`removeSlice`/`add`/`delete`/`merge`/`split`/`rename`/`lock`（`rename` 是 035"改题号"后加的；`addSlice`/`removeSlice` 即"跨页"的加段/去段）。读失败（坏 JSON / 版本更新）一律退化成空覆盖层且**不清文件**——数据留着下次或许能救回来。

**踩过的真 bug**：第一版落盘做 300ms 防抖，而重算是**从文件读回**覆盖层再套用 → 第一次编辑时文件还没写，重算读到空覆盖层，表现为"文件里有 op、库里一点没变"。现在 `run()` 顺序固定为 **保存 → 重算**（一次编辑只写 ~1KB，不值得防抖）。（真机另一半诱因是 adb 短距 swipe 被识别成长按，两者叠加才出现"拖框不生效"。）

### 5.2 anchor：题号｜起始页｜起始y

重切后 `ordinal` 会整体位移，拿序号当身份必然错位。`anchorKey(label, page, y)`（`edited_question.dart:122`）= `page < 0 ? '$label|none|0' : '$label|$page|${y.round()}'`。

匹配（`correction.dart:_resolve` 与 `id_keep.dart` 同一口径）：① 精确 key → ② 退化「同题号（`normalizeLabel` 去空白）+ 同页 + **y 差 ≤ 80pt**」取最近 → ③ 都锚不上就**跳过但不删数据**（悬空修改留在文件里）。容差 `defaultTolerance = 80` 与覆盖层刻意一致；单测锁"重切后 y 抖动 ±40 仍锚定，差太远跳过且不删数据"。

**副作用**：key 含 y，拖动会改 key。所以 UI"选中"存的是锚点、渲染时再解析成当前 key——否则"拖一下就丢选中，下一次操作还打在旧 key 上"。

### 5.3 八种编辑

拖动 / 缩放 / 新增 / 删除 / 合并 / 拆分 / 跨页 / 锁定，全部走同一条命令链，撤销即弹栈重算。语义要点：**删除是软删除**（不落库但留在覆盖层里，重切后能按 anchor 找回）；**合并**保留先出现者、后者标删除、同页取并集（当前只支持"并入上一题"）；**拆分**上段留原题、下段成新题接最后，**拆分点太贴边则不动**（不产生碎片框），只支持上下切一刀；**「一键接受」= 锁定**（`LockCorrection`）**不是清空覆盖层**——规格原文"清空 corrections"实为"丢弃我的修改"，与"接受"字面相反，放弃修改另有入口（删文件回纯自动结果）。

**每次编辑 = 整卷重算**，不写增量：只有一条写库路径，不会出现"UI 与库两份真相"（文本层不重抽、切题 <1ms，够快）。连续编辑会撞上"同卷只跑一个"的锁，所以重算在控制器里**合并**（跑的时候再来请求记 pending，跑完补一次，保证最后一次生效）。

### 5.4 `question.id` 跨重算稳定

原先每次重算给每道题发新 ULID → **每拖一次框整卷 `question.id` 全换**，"笔迹归属到题"和识别结果的 `question_id` 会全部失联。`domain/region/id_keep.dart`（纯函数）：① 精确 anchor key 一致 → 复用旧 id；② 模糊：同题号 + 同页 + y 差 ≤80pt → 取最近；③ 都对不上 → 发新 id（真新题：手画、拆分下段）。约束：**一个旧 id 只被认领一次**（拆出的上下两段不会抢同一身份）。

| 文件 / 表 | 身份 |
|---|---|
| `layout/text.json` | L0 缓存，可删可重建 |

## 6. 交互口径

### 6.1 两态模型：**点中才可拖**

旧方案"只有框线 12dp 吃指针"已废（手指点不中、滚动中蹭到就触发拖动、想调必须先精确碰边）。

| 态 | 进入 | 行为 |
|---|---|---|
| 只读 | 默认 | 叠加层**完全不参与命中**：写字、滚动、缩放零干扰 |
| 编辑 | 打开「题目区域」 | 画布照常滚动/缩放；**框未选中只挂 tap，选中后才挂拖动** |

滚动中按到框 → 滚动手势赢掉这次 tap → 不误选中更不拖动；点一下（框内任意位置，不要求碰边）→ 选中 → 再拖移动、拖四角缩放；**再点一次已选中的框 = 取消选中**，点框外空白也取消（叠加层在框**下层**加整页 `GestureDetector`，只挂 tap，`HitTestBehavior.opaque`）。不彻底锁死画布手势：一页 10+ 个框时锁死就滚不到下半页了。

### 6.2 框形态与框色：粗圆角 + 中性

**绿/黄/红三色让给判题，当前不参与画框**——三色原本表示切题置信度，判题要表示"答对/存疑/答错"，同色双语义会让用户把"这个框我不确定"误读成"这道题做错了"。

`ui/theme/tokens.dart` 的 `ShqRegion`（路径是 `ui/theme/tokens.dart`，不是 `ui/tokens.dart`）：

| 令牌 | 当前值 | 用途 |
|---|---|---|
| `radius` | **14** | 粗圆角（太小就回到"线框"） |
| `strokeWidth` / `strokeSelected` | 1.8 / **3.0**（原 1.2/2.0，中间一版 2.6） | 选中态**只靠"更粗更实"** |
| `fillAlpha` / `fillAlphaSelected` | 0.055 / 0.12 | |
| `labelHeight/labelRadius/labelSize` | 18 / 9 / 10.5 | 题号胶囊，贴框内左上角 |
| `handleHit` / `edgeHandleHit` | **30 / 26** | 缩放把手命中区（取代旧 `handleSize 11 / handleRadius 3.5`，界面上看不见） |
| `auto` / `autoOnDark` | `#5B6B7C` / `#A9B8C7` | 题目框中性色 |
| `green/yellow/red` | `#2F7A55` / `#A9761A` / `#B03A2E` | 判题预留，当前不画框 |
| `answer` | `#7A5AF8` | 作答框（紫色虚线） |

`_colorOf`（`region_overlay.dart`）当前只区分作答框与题目框：**手画框也不再用主色**（2026-10-24 口径，"是不是手画"由面板文字表达，不靠颜色制造第二套语义）；`ShqRegion.manual = #1F6FEB` 仍在但画框路径已不引用——037 写的"手画框用主色蓝"**已过时**。

### 6.3 三个入口合并成一个 `RegionAction`

⋯ 菜单只留「题目区域」与「缩略图」（"显示题目框"独立开关与 `reader.region_overlay` 键已删）；切模式（分页/滚动）上移顶栏。三个入口共用 `ui/region/region_action.dart` 的 `RegionAction`（文案图标只有一份，否则同一功能三处三种叫法）。

- 当前 `RegionAction` **7 项**：`split`（切开）/ `merge`（并入上一题）/ `extend`（延伸到下一页）/ `lock` / `rename`（改题号）/ `delete` / `addQuestion`（作答块提升为一道题）。
- **贴框浮动条** `kRegionBarActions` = 改题号 + 并入上题 + 删除（高 42、钮 34，窄屏退紧凑态），放框下方、放不下翻上方、再不行贴内侧。不可用动作**灰掉而不是藏起来**（tooltip"已经是第一题"）；删除放最后、错误色。
- **面板**：选中条目下方展开一行动作；`SingleChildScrollView + Column` + 选中行 `GlobalKey` + `Scrollable.ensureVisible(alignment: 0.12)`，画布上点屏幕外的框列表也会滚到它。
- **长按菜单**保留（给"不看就会"的发现路径）。`reader_page.dart` 里 80 行的 `_showRegionMenu` switch 收拢成 `_applyAction(...)` 一条路径。

**踩过的坑**：浮动条"删除无效"根因不是按钮，是 `PageLayer` 构造 `RegionOverlay` 时**漏传 `onDeselect/actionsOf/onAction`**（只传了 `editable/selectedKey/onSelect/onMove/onResize/onMenu`），按钮画出来了回调是 null。另有真机溢出：`Container` 的 1px 边框再占 2px，`widthFor` 少算 2px → `RIGHT OVERFLOWED BY 2.0 PIXELS` 黄黑条，宽度公式已补 2px。

**面板只给用户看用户需要的信息**（036 返工）：删掉三色点/计数、置信度百分比、"未分类"、"建议检查"；保留题号胶囊、第几页、跨页段数、已锁定、手画、题干预览；重切 SnackBar 从"绿 x / 黄 y / 红 z"改成"已切出 N 道题"。标题与题列表之间留 `Widget? dashboard` 槽位。宽度默认 **320dp**，窄屏（<760dp）42%（现已支持拖拽调宽）。

### 6.4 调框模式：手写笔可调框，且不会同时写字

**根因**：`InkLayer` 只收 `stylus`，但它和 `RegionOverlay` 是**兄弟节点**——框的 `GestureDetector` 在墨迹层之上能拿到笔的 tap/pan，而墨迹层在 `onPointerDown` 直接起笔（不看手势竞技场结果）→ "笔一边拖框、一边落墨"。

**改法**：`PageLayer` 新增 `inkInteractive`（默认 true）→ 传给 `InkLayer.enabled`（只画已有笔迹、不收输入；`inkEnabled` 仍决定"要不要建墨迹层"）；两个 ReaderView 透传 `inkInteractive: !regionEditing`；`ReaderPage` 面板打开时 `regionEditing: _panelOpen` 并**隐藏笔刷浮钮**；`RegionOverlay` 空白 tap 层改 `opaque`，不再把指针漏给墨迹层。退出面板后恢复收笔；滚动/缩放仍由父层手势处理（子层 opaque 不阻断祖先手势）。

### 6.5 拖动跳闪：抬手保留预览

**根因**：旧 `_commitMove`/`_commitResize` 抬手时**立刻清预览**再回调；父层要走"保存 corrections → 整卷重算 → 事务写库 → provider 失效"，这中间框先弹回原位、等新数据回来再跳到新位置 —— 视觉上跳一下。

**改法**（`region_overlay.dart:238–565`）：抬手设 `_commitPending = true`，**不清 `_previewRect`**；父层新 marks 回来时先认精确 key，再退到"同题号 + 同页 + rect 与预览一致"（拖动/缩放会改 anchor key）；旧 key 消失且 marks 确实换了才清预览、显示权威 rect（可能被页边距夹过）；**1.5s 安全定时器**兜底；连续拖动时下一次 `_startDrag` 从**屏幕上的预览位置**起算。

### 6.6 笔刷浮窗自动收起

`InkFab`（现位于 `ui/reader/ink_toolbar.dart:40`）的展开面板 + 圆钮整体包 `TapRegion`，`onTapOutside` 收起：点书写区、顶栏撤销/重做、题目区域、⋯ 等**任何外部指针按下**都先收起；不用全屏遮罩（滚动/缩放/书写手势仍按原路径走）；点面板内部不收起（方便连续调色）。

## 7. 公式可读化（只解决"显示"，不解决"识别"）

**诊断**（从设备 `shuaqi.db` 取原始 stem：`1. 设fx()=\uF0ED ,则f\uF0E9\uF0F9\uF0EB\uF0FBf(x) = 1 . \uF0EF\uF0EE0,x\uF03E1`）：**显示层**是数学 Unicode / PDF 私有区缺字形（豆腐块 `□`），**识别层**是 PDF 文本碎片顺序错乱（`设fx()` 应为 `设 f(x)`、`nlim→` 应为 `lim n→`）。只加数学字体解决不了顺序，只重排文本解决不了 PUA。

**已做三件事（无新依赖）**：

1. **`domain/region/math_text.dart`**（`mathForDisplay`/`formulaHeavyText`）：数学字母 U+1D400–U+1D7FF → ASCII；常见符号 → 可读 ASCII（`≤`→`<=`、`∞`→` inf `、`√`→`sqrt`、`∫`→`int`…）；PDF 私有区 `0xF0ED`→`{`（piecewise 左花括号）、`0xF03E`→`>`、`0xF03C`→`<`、`0xF0A5`→` inf `、`0xF0B9`→`!=`、`0xF07B/0xF07D`→`{}`；**认不出的 PUA 一律丢掉**（宁少一个装饰括号，不出豆腐块）；清零宽/方向控制字符。**入库数据不动**——`question.stem_text` 仍保留原始 Unicode，喂 AI/检索时信息不丢。
2. **题干按行保留换行**：`_buildStem` 从"行间拼空格"改成 `'\n'`（split.dart:533），面板 `maxLines` 2→4。piecewise 公式至少按行可读，不再压成一条乱序串 → `kCutterVersion` 3→4。
3. **选中题的 PDF 原图裁切预览**（`ui/panel/region_preview.dart` 的 `RegionPreview`）：面板标题下方显示当前选中题的**卷面裁切**（不是文本层），公式按矢量原样；宽 = 面板宽、最高 150dp，取 `PageImageCache.obtain` 的独立 clone、用完 dispose。对扫描件同样有用。

**真机**：面板不再出现 `□`（`设f(x)={,则ff(x)=1. 0,x>1`、`nlim-> inf( ... )`）；选中题出现题面预览。**顺序仍是 PDF 碎片位置的近似**。

**要"排版级"还原**需先识别成 LaTeX 再用 `flutter_math_fork`（白名单已有、未安装）渲染：光装插件不够（`stem` 里没有 LaTeX 只有碎片），建议顺序 **第 4 周 AI 按题识别 → 输出 LaTeX → 再装插件渲染**。

### 已知限制（不要当 bug 重查）
| 项 | 现状 | 何时处理 |
|---|---|---|
| 扫描件含题内解析 | 无文字，`（1）(2)` 仍被切成独立小题；用「并入上题」并回 | 等 OCR（引擎 B）或加"含解析"开关 |

| PUA 未知码位 / 预览只取顶部 150dp | 认不出的一律丢掉（可能少一个装饰括号）；长题只看得到开头 | 有 cmap 或 OCR 后补 / 需要时展开全图 |

| 题号样式 | `1.` `12、` `（1）` `一、` 稳定；`1)` `【例5】`、三位数、圈号可能漏 | 有真实语料再补 |
