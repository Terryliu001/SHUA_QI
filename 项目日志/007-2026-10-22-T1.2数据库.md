### 两个设计取舍

1. **`setting` 单独放在 v2。** T1.2 说"本周只建 6 张表"，但本周的 §3 又要写
   `reader.default_mode` 这类键。与其把 7 张表硬塞进 v1（违反"只建 6 张"），
   不如让 v1 严格等于规格的 6 张，v2 加 `setting` —— **顺带让"迁移机制"有了第一个真实用例**，
   而不是为了测试而造一个假迁移。
2. **`SessionState` 的推进用 `WHERE state = ?` 兜底。** `markSubmitted` 只对 `draft` 生效，
   返回 0 表示状态不对。这样"交卷后又被改回 draft"在 SQL 层就不可能发生。

## 3. 一个必须记住的架构决策：测试金字塔被环境逼着改了

### 3.1 现象

加了 `pdfrx` 之后，`flutter test` 直接挂：

```text
pdfrx_pdfium_gate.c(17): fatal error C1083: 无法打开包括文件: "windows.h"
Building native assets failed.
```

**根因链**：`pdfrx → pdfium_dart` 是 native assets 包 → `flutter test` 在**宿主机 Windows** 上
也要编译它的 gate 库 → 编译需要 Windows SDK 头文件 → `native_toolchain_c` 通过**查注册表**
（`reg.exe`）定位 Windows SDK → **本机沙箱禁止 `reg.exe` 启动** → INCLUDE 里没有 Kits 路径。

试过的两条死路：
- `flutter config --no-enable-native-assets` → `flutter test` 直接拒绝：
  `Package(s) objective_c pdfium_dart sqlite3 require the dart assets feature to be enabled.`
- 手动补 `INCLUDE` → hook 进程的 INCLUDE 是 `native_toolchain_c` 自己重建的，覆盖外部设置。

`sqflite_common_ffi` 同理：它依赖 `sqlite3` 包，也是 native assets 包。

### 3.2 解法（两条，都写进代码注释了）

**① pdfrx 暂时移出 `dependencies`。** T0.4 已完成、数据已入库，spike 归档到
`spikes/_archive/pdf_spike/`（并在 `analysis_options.yaml` 里 exclude）。
T1.5 做阅读器时加回来，同时重跑 `tool/patch_pdfium_mirror.py`。

**② DB 测试搬到 `integration_test/`，跑真机 sqflite。**
```bash
flutter test integration_test/db_test.dart -d VO697TPJ9PVGEAFI
```
这比在桌面跑 ffi 更**真**（就是产品实际用的 sqflite），代价是必须有设备。

**为什么值得为这件事折腾**：`domain/` 层将来装着几何归属、判题、公式判别、LaTeX 后处理——
这些必须有**秒级反馈的宿主机单测**。为了一个 DB 测试把整个宿主机测试能力废掉，是本末倒置。
现在的分工是：

| 测试类型 | 位置 | 运行方式 | 现状 |
|---|---|---|---|
| 纯 Dart / Widget | `test/` | `flutter test`（宿主机，秒级） | **18 passed** |
| 真库 / 真设备 | `integration_test/` | `flutter test ... -d <设备>` | **10 passed** |

### 3.3 顺带一个坑

`flutter test -d <设备>` 也会被 `http_proxy` 打断（`WebSocketException: ... was not upgraded`）。
必须清代理变量再跑——和宿主机测试同一条规矩。`tool/run_tests.sh` 已经处理了宿主机侧。

需要新增两个白名单依赖（都会下载，走镜像/正常源）：
- `file_picker`（选 PDF；规格 §5.3 白名单内）

要点（按 T1.3 的坑预先规避）：

3. 顺序是「建目录 → 写文件（.tmp + rename）→ 事务落库」，中途崩溃只留孤儿目录，
   启动时做一次孤儿清理。

> 先写纯 Dart 的路径约定（`infra/vault/paths.dart`）与 sha1 工具并单测，
