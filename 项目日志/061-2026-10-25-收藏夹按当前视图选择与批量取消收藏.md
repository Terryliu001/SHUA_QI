## 1. 选择跟随当前视图

之前进入多选会统一铺成"全部"，导致：
- 在「按知识点」选了某标签，进多选后看到的是全部题；
- 在「按试卷」点不了文件夹；
- 「全选」永远选全部收藏。

现在：
| 视图 | 多选时 | 全选 |
|---|---|---|
| 全部 | 题卡可勾 | 当前列表全部题 |
| 按试卷 | **点文件夹 = 整卷选中/取消**，卡上显示 `5/5`、半选 `2/5`、整卷主色描边 | 当前所有卷的题 |
| 按知识点 | 保留标签条，当前标签下的题卡可勾 | 只选当前标签（或未归纳）下的题 |
| 搜索 | 命中的题卡可勾 | 只选命中的题 |

「组卷」是题集列表，不是题目，保持不显示选择入口（有搜索词时搜索页仍可选题）。

真机：
- 全部 → 全选 **9 题**；
- 按试卷 → 点新导入的数学分析卷（1/1）+ 旧 midterm 卷（5/5）→ **6 题**；
- 按知识点 → 标签「极限」→ 全选 **1 题**（只剩这一题在该标签下）。

## 2. 多选底部：取消收藏

底部顺序：**取消收藏 · 点亮知识点 · 组卷**。
- 只在有选中时可用；
- 二次确认：「取消收藏 N 题？只删除这些题的收藏快照，原卷与作答不受影响。组卷里的成员也会一并移除。」；
- 确认后逐题 `FavoriteStore.remove`，刷新收藏夹/组卷，退出多选并提示数量。

## 3. 顺手修：批量删卷漏标收藏

发现书架**批量删除**只做了 `dao.delete + vault.deleteWorkbook`，没有像单卷删除那样调用 `markSourceDeleted`；结果收藏夹仍显示"原卷还在"，看题页「回看出处」会点进空卷。

修复：
- `_batchDelete` 删除前统计这些卷的收藏数，确认框写"这些卷的 N 道收藏会保留，只标记「原卷已删」"；
- 删除后逐卷 `markSourceDeleted`，并刷新收藏夹；
- 启动时自愈：`bootstrap` 里把 `workbook_id` 不在 `workbook` 表的收藏补标 `source_deleted=1`（覆盖历史漏标数据）。

> 本轮真机上用户已手动重新导入 3 份 PDF（书架 3 卷）；旧收藏 8 道按新逻辑显示「原卷已删」，新导入的数学分析第 4 题正常。旧卷的 PDF 仍在 `/sdcard/Download`（四级原卷未找到），需要可重新导入。
