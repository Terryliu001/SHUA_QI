## 1. 本轮改动（5 项）

### 1）多选批量收藏：再次点击取消

- **语义**：
  - 选中的题**全部已收藏** → 批量按钮显示「取消收藏」，点击删除这些收藏（快照目录一并删）。
  - 选中的题**全都没收藏** → 「收藏」，全部补收藏。
  - **混合** → 只补没收藏的；已有收藏不动（不偷偷删），提示「已收藏 N 道 · M 道本来就在收藏夹」。
- 落点：`ui/reader/reader_page.dart` `_runBatch(RegionPanelBatch.favorite)`；`ui/panel/region_panel.dart` `_BatchBar` 标签。
- 单题星标本来就是切换，未改。

### 2）词云：逐字粒子化 + 搅动 + 弹性聚合

- `ui/records/records_word_cloud.dart` **沙盘重做**：
  - 每个字是一个带速度的粒子（`_Particle`），整块词云是一个沙盘。
  - 手指在框内任意位置划过，88px 内的字受到切向+径向力，有惯性；**不是"拖某个字回原位"**。
  - 所有粒子在 `_onTick` 里步进并 clamp 在框内，撞边反弹，**不会出界**。
  - 松手重新随机排一遍词的目标位置（随机顺序 + 8px 内抖动），再用弹簧/阻尼慢慢归位；每次回到中间的排布可以不同。
  - 同一个词的字共用词目标 + 字内偏移，归位后仍拼在一起，不会散。
  - 大量文字：
    - 参与布局的词数按面积决定（8–22 个），放不下的在右下角标 `+N`，不假装全画了；
    - 先整体缩字号重排（最多 5 档，最低到约 0.56 倍），仍放不下才对单词再缩；
    - 极长/极小字（<7px）不再硬塞，避免糊成一团。
- 可调参数（下一位 UI 优化重点）：
  - 搅拌半径 `88`、初始冲量 `160`、持续力 `240 + speed*1.6`；
  - 回位弹簧 `22`、阻尼 `6.5`；
  - 目标抖动 `±5px` / 字号 11–30。
- 注意：布局缓存 `_layoutCache` 上限 3 份；`_CloudLayout.dispose` 同时释放整词 painter 与逐字 painter。

### 3）时间线「按试卷」打不开卷

- 根因：`groupTimeline` 把分组的 **key**（`w:<卷id>` / `a:<attemptId>`）塞进了 `TimelineWorkbook.workbookId`，`_openWorkbook` 拿它当真实卷 id 打开，阅读器找不到卷。
- 修复：
  - `TimelineWorkbook` 新增 `groupKey`（只用于展开/去重）。
  - `workbookId` 改回**真实来源卷 id**（`first.workbookId`）。
  - `timeline_page` 展开状态用 `groupKey`；打开卷/长按菜单用真实 `workbookId`。
- 落点：`domain/records/records_stats.dart`、`ui/records/timeline_page.dart`。
- **不要**再把 `groupKey` 当卷 id 传阅读器。

### 4）AI 补答案：逐题实时写回 + 不跳转

- `_fillAnswersWithAi` 与 `_gradeSelectedWithAi` 的补答案阶段：
  - 每得到一道答案就 `writeAiAnswers` 落盘，再更新 `_liveAiAnswers` 内存覆盖并 `setState`；
  - 不再等整批结束才写。
- `_liveAiAnswers` 通过 `_withLiveAiAnswers` 叠到 `_regionSetOf` 和 build 的 `regionSet` 上，
  所以面板/对答案立刻能读到，但**不 invalidate provider、不跳页**。
- 整批结束才 `ref.invalidate(regionSetProvider)` 同步一次（此时用 `.value` 保留旧数据，避免面板空一下）。
- 单题快捷「先做一遍」的 `_saveAiAnswer` 同样落盘 + live + 收尾同步。
- 进卷 `initState` 主动 invalidate 一次切题/答案 provider：避免退出重进时 provider 缓存旧文件。
- 中断：每道答案已落 `answers_ai.v1.json`，退出/被杀最多丢"正在请求的那一道"。
- 注意：`answers_ai.v1.json` 与 PDF 抽出的答案合并仍用 `mergeMissing`，PDF/已有答案优先。

### 5）收藏夹多选返回键只退出多选

- `ui/favorites/favorites_page.dart` 外层加 `PopScope(canPop: !_selecting)`；
  多选时返回键 → 清空选择、留在收藏夹；不选中时返回键行为不变（可退出 App）。
- 顶部「关闭」/「取消」仍保留。

## 3. UI/交互优化交接（下一轮重点）

### 3.1 词云（优先级最高，用户刚提过）

需要下一轮重点看：

1. **可发现性**：现在没有任何提示"字可以搅"。建议在词云角落加一句很轻的提示（如「在字上划一下」），或首次出现时淡入一次，不要常驻抢视线。
2. **手感**：当前搅拌半径 88、初始冲量 160、回位弹簧 22/阻尼 6.5；下一位可以调成更"流体"或更"粘"的手感。要求仍然是：**回位后同一个词的字在一起**，且每次归位允许不同。
3. **大量文字**：按面积只取 8–22 个词，右下角 `+N` 提示被省略的数量；整体字号先缩（最多 5 档），仍放不下才缩单词。下一位可决定是否把 `+N` 做成可点开完整列表。
4. **边界**：粒子有撞边反弹；如果觉得"撞墙"太硬，可改恢复系数 0.28。
5. **数据**：词云数据来自 `records_stats` 的科目/题型聚合；`CloudWord` 的 label 是展示名。用户口中的"文件名"在代码里就是这些 label；不要改成真实文件路径。

### 3.2 其他建议

- **时间线**：按试卷卡现在能打开真实卷了；可加"打开的是哪一次/哪一题"的轻提示，避免用户不知道落在哪。
- **批量收藏**：混合状态只提示 toast；可考虑按钮旁显示 `3/5 已收藏` 的状态，减少误触。
- **AI 补答案**：逐题进度已有 `_fillDone/_fillTotal`；可把"刚补好哪道题"做成轻量高亮，但不要自动跳题。
- **返回键**：收藏夹已处理；阅读器/看题页/重刷页如果还有"多选/编辑态"的返回键语义，按同一原则检查。
- **图形吸附/裁剪**：本轮没动；上一轮交接 `071` 的"图形视觉、双指裁剪"仍待走查。

## 5. 不要改坏的约定

- `TimelineWorkbook.groupKey` 与 `workbookId` 是两件事：前者分组，后者打开卷。
- AI 答案实时显示靠 `_liveAiAnswers` 叠加，**不要**改回"每补一题 invalidate provider"（会闪/跳）。
- 批量收藏的"全收藏=取消、混合=只补缺"不要改成"混合也删"。
- 词云归位目标可以每次不同，但**同一词的字必须共用词目标 + 字内偏移**；不能各自随机，否则文件名会散。
- `PopScope` 只包收藏夹；不要在全局壳层加 `canPop:false`，否则其他页面返回会坏。
