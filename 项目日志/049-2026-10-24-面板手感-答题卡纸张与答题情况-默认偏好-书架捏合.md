## 1. 面板手感：拖宽跟手（用户第 10 条）

### 1.1 根因

旧实现把把手抛来的**每帧位移**累加再 clamp：
`_dragPanelWidth = clamp(_dragPanelWidth + grow)`。
一旦拖过 1/2 屏，宽度被卡在 600，继续拖时每帧的 clamp 都在丢位移；
往回拖要先"把丢掉的位移补回来"才动——手感就是"不跟手"。

### 1.2 修法

- 把手只在拖动开始时记一次**起点 x**，之后每帧抛「起点到现在」的**总位移**；
- 面板用 `_dragStartPanelWidth + totalGrow` 算宽度，超限只是暂时夹住，手一反向立刻跟手；
- 命中区 16dp → **28dp**（视觉杆仍是 4dp），400dpi 平板上"按准"的成本远大于让出的 12dp。

真机：拖到 600dp 卡住后直接往回拖，第一帧就跟手。

## 4. 「重框 → 返回 / 停留」闭环（用户第 3 条）

答题卡顶栏「重框」→ `Navigator.pop(AnswerSheetResult.adjust(questionId))` →
阅读器收到后：打开面板、选中该题、进作答框编辑、左上角出小浮窗。

浮窗只有两个动作（`ui/panel/answer_adjust_bar.dart`）：

| 按钮 | 行为 |
|---|---|
| **停留** | 保存（切题覆盖层/作答框/顺序/判题/笔迹一起 flush）→ 浮窗消失，人留在原卷 |
| **返回** | 同上保存 → 按 `questionId` 重开答题卡并**定位到这道题**（重算后 id 变了就按 anchor 回落） |

`showAnswerSheetPage` 新增 `initialQuestionId`：进页面时直接定位，`PageController(initialPage:)` 同步。

真机：重框 → 阅读器选中第 1 题 + 浮窗在场 → 点「停留」→ 浮窗消失 + 「修改已保存」。

## 6. 默认偏好 + 书架捏合（用户第 5、6 条）

### 6.1 默认滚动 + 手势，且**不按卷记忆**

- `ReaderPrefs.defaults`：`mode = scroll`、`handTool = true`；
- `ReaderPrefsStore.load()` 直接返回全局默认，**不再读 `reader.view.<id>`**（用户选"直接忽略"）；
- `save()` 也写全局（`reader.default_mode / paper_style / intensity / hand`，新增 `defaultHand`）；
- 设置页「阅读默认」加"手势模式"开关；
- 答题卡也接这份偏好：`showAnswerSheetPage(handTool:)`，默认手势模式（手指不落墨、笔写）。

### 6.2 书架双指捏合

- `_content` 外包 `RawGestureDetector` + 自定义 `_TwoFingerScaleRecognizer`：
  **第二指落下才 accept**，单指照常滚动、点击、长按；
- `details.scale` 连续改 `_cardScale`（0.75–1.55），松手落库；
- 读库不再吸附到 5 档（滑块仍按最近档显示）。

为什么不用 `GestureDetector(onScaleUpdate:)`：它的 ScaleGestureRecognizer 单指也会 accept，
会把 GridView/ListView 的滚动抢掉——书架直接滑不动。
