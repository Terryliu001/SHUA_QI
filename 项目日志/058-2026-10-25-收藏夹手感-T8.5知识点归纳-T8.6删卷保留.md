## 1. 用户四条反馈：怎么落的

### 1.1 组卷里长按拖动排序

- `FavoriteSetPage` 的成员列表从 `ListView.separated` 换成 `ReorderableListView.builder`；
- **整行长按即可拖**（`ReorderableDelayedDragStartListener`，`buildDefaultDragHandles: false`）：
  平板手指粗，只给右侧小把手不好按；
- 行内原来的"长按弹菜单"会让两个长按抢手势，所以菜单改由行尾 **⋯** 承担
  （看题 / 从这题开始刷 / 移出）；行尾另有 `drag_indicator` 作为"可拖"的视觉提示；
- 落库：`FavoriteDao.updateSetItemSort` + `FavoriteStore.reorderSet`
  （按新顺序重写整卷 `sort`，再 touch 组卷），连刷读 `setItemIds` 的顺序，天然同序。

**证据**：把「数学分析第 3 题」从第 2 位拖到第 1 位后：
- UI 顺序变 `第 3. 题 / 第 6 题 / 第 1. 题`；
- DB：`[(0,'3.'),(1,'6'),(2,'1.')]`；
- 点「开始连刷」首题 = 第 3. 题（截图 `17-reorder.png`、`18-redo-new-order.png`）。

### 1.2 重刷答题纸 + 笔刷两形态

**答题纸**：新增 `favorites/<id>/paper.json`（`FavoriteRedoPaperStore`），四项都可设：

| 项 | 复用/实现 |
|---|---|
| 尺寸/方向/纸样式 | 复用 `showAnswerPaperSheet`，新增 `showApplyAll:false`（每收藏一份）、`showPages:true` |
| 张数（1–9） | 同上，浮层里给加减器（重刷页没有答题卡画布上的「＋」） |
| 纸样式绘制 | `_AnswerPaperPainter` 从 `answer_sheet_page.dart` 抽成公共 `AnswerPaperPainter`（答题卡与重刷同一套线距/留白） |
| 换尺寸不丢笔迹 | `FavoriteRedoInkStore` 读 `paper.json`：编码用当前纸尺寸，读旧文件时 `scaleInkDoc` 等比搬 |
| 每张纸独立笔迹 | `InkPageKey(session, paperIndex)` → `favorites/<id>/ink/p0.sif`、`p1.sif`… |

**笔刷两形态**：复用阅读器的 `inkToolbarPinnedProvider`（全局一份）——
- 固定：AppBar 下方 `_RedoToolbar`（工具/颜色/粗细/撤销重做 + 「缩小为浮钮」）；
- 浮钮：直接复用 `InkFab`（右下 56dp 圆钮，展开工具/颜色/粗细；面板自带「固定到顶栏」）；
- 撤销/重做在浮钮形态下移到 AppBar（阅读器同口径：文档动作放顶栏）。

**证据**：A4 横向 + 点阵 + 2 张纸（截图 `03-paper-a4-dots-2p.png`）；
第 2 张写一笔、回第 1 张原笔迹还在（`04/05`）；固定/浮钮两形态与浮钮面板（`13/14/15`）。

### 1.3 问 AI：顶栏按钮 + 右侧面板（复用）

**直接复用 `AiChatPanel`**（阅读器那块 2000 行的面板），不新写一套聊天 UI：

- 新增 `FavoriteAiPanel`：只做三件事——把快照准备成面板输入、把流式对话接到 `AiService.chat`、
  把快捷动作接到 `solve/grade` 并写回快照；
- 宽度/拖拽：`panelWidthProvider` + `PanelMetrics` + `PanelResizeHandle`，与阅读器**同一个全局宽度**，
  左缘拖拽、最大 1/2 屏；
- 入口：看题页与重刷页 AppBar 都是 `IconButton.filledTonal`（`auto_awesome`，选中变实心），
  面板从右滑入、内容区让位；
- **共用一份对话**：`favorites/<id>/chat.json`；看题页问过的历史，在重刷页打开就是同一份
  （真机截图 `22-view-ai-panel.png`：重刷页里问的两轮，看题页面板里原样在）；
- 未配置：面板内直接给「还没有配置 AI + 去配置」，输入框提示"先配置 AI，才能发送"，
  点发送 → `_send` 里 `_openConfig()` 直接弹 `AiSettingsSheet`（不再是一句 SnackBar）；
- 发送键：复用面板自带的**实心 `FilledButton`「发送」**（暗色下对比明确），
  未配置时同一位置变「配置 AI」实心按钮——用户第 3 条的"不明显"随之消失；
- 快捷动作：`先做一遍`（solve，结果只回在对话里）/`判我的作答`（grade，写
  `grading.json` + 更新 `favorite.verdict`，卡片判定点立即变绿/红）。
  `讲这道题` 走普通流式对话。

**证据**（假 SSE `adb reverse tcp:8787`）：面板未配置态（`06`）→ 配置框（`08`）→
流式公式回复（`09`）→ 先做一遍写参考答案（`10`）→ 判题「对 · 已记入判题」（`11`）→
收藏卡片判定点变绿（`20-source-deleted.png` 里那颗绿点）。

## 3. T8.5 知识点 AI 归纳

### 3.1 链路

- `domain/ai/knowledge_tag.dart`：`KnowledgeTagItem`、system/user 提示词、**宽容解析**
  `parseKnowledgeTagResponse`（支持 `{"tags":{id:[...]}}`、`[{id,tags}]`、顶层 id→标签、
  markdown 围栏；空/无可用标签返回 null）；
- `AiService.tagKnowledge`：**一次请求**归纳一批（收藏夹「未归纳」通常十几道，逐题发是十几次往返）；
  只发文本（题号+卷名+题型+题干），不依赖题面图；
- UI：按知识点视图标签条末尾「✨ AI 归纳」（有"未归纳"才出现）；
  - 没配 AI → 直接 `showAiSettingsSheet`；
  - 运行中 chip 显示「归纳中…」；
  - **只改此刻仍无标签的题**（AI 跑的时候用户手改过就跳过，不覆盖人工结果）；
  - 失败不写半份。
- 解析规则：去空白/去重/单个 ≤20 字/每题最多 5 个（沿用 `KnowledgeTags`）。

### 3.2 真机验证（假 SSE）

对 5 道收藏点「AI 归纳」，写回结果：

| 收藏 | 卷 | 归纳标签 |
|---|---|---|
| 第 3. 题 | 数学分析（上）期中 | 极限, 函数 |
| 第 6 题 | 习概期末 | 政治理论 |
| 第 1. 题 | 四级真题 | 英语词汇 |
| 第 1./2. 题 | math_analysis_midterm | 假归纳（假服务器没命中关键词） |

UI 立即出现 假归纳(2)/英语词汇/极限/函数/政治理论 分组（截图 `16-ai-tags.png`），
「AI 归纳」入口因没有未归因而自动消失——口径正确。

> 假服务器的归纳是"按卷名关键词给固定标签"，只证明链路，不证明模型质量；
> 真实模型效果要等用户填 Key 后复测（用量记录 task=`tags`）。

## 5. 顺手修 / 顺手改

1. **「原卷已删」被省略号吃掉**：卡与组卷行都改成前缀（见 §4）。
2. **AI 面板的返回键**：`AiChatPanel.onBack` 改可空；收藏夹没有"上一层面板"就
   不画返回键（否则返回/关闭两个键都收面板，语义重复）。
3. **`onReorder` → `onReorderItem`**：Flutter 3.41 起旧的 `onReorder` 的 `newIndex`
   语义（含"移出后左移"补偿）已废弃；新回调自己扣掉，`_reorder` 不再手动 `-1`。
4. **组卷行手势冲突**：去掉行内长按菜单，菜单改 ⋯（见 §1.1）。
5. **纸张浮层的"张数"说明文案**加 `Flexible`，窄屏不溢出。

## 9. 已知限制 / 遗留

1. **知识点"跨组拖拽改归属"没做**：现在改归属走长按菜单「编辑知识点」（输入标签）或
   标签条「＋」批量归类；把卡片从 A 组拖到 B 组要重做分组墙的手势/命中，留到下一轮。
2. **AI 判题依赖作答图**：快照没有可靠的 OCR 文本，`studentAnswerText` 传空，
   模型只看图；纯文本模型 + 关闭传图时会报"没有可判的作答"。
3. **重刷多张纸的 AI 附件只带第 1 张**（`FavoriteAiPanel` 读 `pageIndex 0` 的重刷图）；
   多张纸的完整附件需要按当前纸传页码。
4. **真删带收藏的卷没有实操**（见 §4）；`source_deleted` 的 UI 分支已单独验证。
5. 组卷排序没有"撤销"；目前是即时落库。
6. 归纳结果没有"撤销"按钮：改错了要么重跑 AI，要么手动编辑。
