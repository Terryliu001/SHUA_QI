## 1. 为什么收藏必须是「独立快照」

用户需求：原卷删除后，收藏的题目仍可查看（题面、笔迹、AI 问答）。旧实现是每卷
`layout/favorites.v1.json` 存一列 question_id——卷删除时 `question` 表 CASCADE 清空、
卷目录整棵删掉，收藏随之蒸发，与需求直接冲突。

所以 v6 的 `favorite` 表**不设任何指向 workbook/question 的外键**，只留
`question_id` / `workbook_id` 做溯源，`source_deleted` 标记来源卷已删；
快照文件放顶层 `favorites/<id>/`（与 `workbooks/` 平级，孤儿清理只扫 `workbooks/`，不会误伤）。

用户已确认的口径（2026-10-25）：
- 快照**完整且隔离**：收藏夹里的作答/问 AI 改动不与原卷冲突；
- 二刷 = 单题就地重刷 + **组卷冲刷**（可保存多份命名题集，只活在收藏夹，不上书架）；
- 知识点 = 自由标签（AI 归纳 + 手动改），知识树以后再说；
- 默认呈现 = 按更新时间倒序的「按卷分组」卡片墙，卡片含题面预览/来源/知识点·题型标签，排版整齐。

## 2. 数据契约

### 2.1 DB v6（只追加）

```sql
CREATE TABLE favorite(
  id TEXT PRIMARY KEY,
  question_id TEXT NOT NULL DEFAULT '',      -- 溯源，卷删后仍在但题已无
  workbook_id TEXT NOT NULL DEFAULT '',      -- 溯源，同上
  workbook_title TEXT NOT NULL DEFAULT '',   -- 卷名快照
  label TEXT NOT NULL DEFAULT '',            -- 题号原文
  ordinal INTEGER NOT NULL DEFAULT 0,
  kind TEXT NOT NULL DEFAULT 'unknown',
  stem_text TEXT NOT NULL DEFAULT '',
  page_index INTEGER NOT NULL DEFAULT 0,
  rect TEXT NOT NULL DEFAULT '',             -- RegionRect JSON，收藏那一刻定格
  knowledge_tags TEXT NOT NULL DEFAULT '',   -- 逗号分隔，≤5 个每个 ≤20 字
  verdict TEXT NOT NULL DEFAULT 'none',      -- AnswerVerdict.name
  source_deleted INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE INDEX idx_favorite_updated ON favorite(updated_at);
CREATE INDEX idx_favorite_workbook ON favorite(workbook_id);

CREATE TABLE favorite_set(  -- T8.4 组卷用，本轮只建表
  id TEXT PRIMARY KEY, name TEXT NOT NULL,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL);
CREATE TABLE favorite_set_item(
  set_id TEXT NOT NULL REFERENCES favorite_set(id) ON DELETE CASCADE,
  favorite_id TEXT NOT NULL REFERENCES favorite(id) ON DELETE CASCADE,
  sort INTEGER NOT NULL DEFAULT 0, PRIMARY KEY(set_id, favorite_id));
CREATE INDEX idx_favorite_set_item_set ON favorite_set_item(set_id);
```

真机从 v5 原地升级正常，旧卷/旧设置全在。

### 2.2 Vault 快照 `favorites/<favoriteId>/`

| 文件 | 内容 | 缺省 |
