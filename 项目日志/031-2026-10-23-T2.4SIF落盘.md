## 1. 目标与验收（规格 03-第2周 §T2.4）

- 单页 5000 笔 SIF ≤400KB；
- 编解码往返坐标误差 <0.01pt（实际见 §3，u16 量化物理达不到，已如实记录）；
- 强杀进程后重开，笔迹与退出前一致；
- 人为截断文件：能走 `.bak` 或给明确提示，不崩溃。

## 2. 文件格式（v1，整文件 zlib）

```text
zlib( Header 16B | Stroke × n | Footer 4B )
Header: 'SIF1' | flags u8 | pageW u16 | pageH u16 | nStrokes u32 | reserved 3B
        pageW/pageH 单位 = 0.1pt（841.89pt → 8419）
Stroke: style u8 | color u8 | width u8 | flags u8 | nPoints u16
        | bbox 4×u16 | t0 u32
        | points(dx,dy zigzag LEB128) | pressure(4bit × n，两点一字节)
Footer: crc32(Header+Strokes) u32
```

与规格文本的**三处有意差异**（都是 025 的契约变更/物理精度导致）：

1. stroke 头加 `color` / `width` 各 1 字节：T2.2 已把颜色与粗细写进 `InkStroke`，
   SIF 必须跟着存，否则重启后旧笔会变黑/变中粗；
2. 每点压力用 **4bit（15 级）**：规格只写了坐标；但钢笔线宽靠压力，
   丢掉压力等于"重启后笔迹变一种样子"。4bit 比 1 字节省一半，肉眼不可辨；
3. 页尺寸用 **0.1pt 定点**存 u16：直接存整数 pt 会让 841.89→842，
   在长边上累积出约 0.2pt 误差。0.1pt 后实测最大往返误差 ≈0.035pt。

其他约定：
- 单笔 >4096 点拆成多笔同款式碎片（z 序不变，点数总量不丢）；
- UID 不进文件（它是会话内身份），解码时用 ULID 重新生成；
- 只存每笔 `t0`，解码时第 i 个点 `t = t0 + i`。逐点时间戳不参与屏显/识别，
  真要用于速度特征再升 v2（加 flags 位即可，不破坏老文件）。

## 3. 实现与关键取舍

| 层 | 文件 | 做了什么 |
|---|---|---|
| domain | `domain/ink/sif_codec.dart`（新） | Header/Stroke/CRC/zigzag varint/4bit 压力/拆分；纯 Dart，可单测；zlib 用白名单内的 `archive 4.5.2` |
| domain | `domain/ink/ink_store.dart` | 加 `InkLoadIssue` + `InkIssueReporter`（不改 `InkStore` 签名） |
| infra | `infra/ink/sif_ink_store.dart`（新） | 查页尺寸 → isolate 编码 → 旧文件 `.bak` → `.tmp` 写入 flush → rename → `ink_state` upsert；载入主文件失败读 `.bak`，成功则**把备份写回主文件** |
| infra | `infra/ink/ink_writer.dart`（新） | 500ms 防抖、同页只留最后一次、同页写串行、失败保留快照、`flushAll` |
| infra | `infra/db/dao/ink_state_dao.dart`（新） | `INSERT ... ON CONFLICT(page_id) DO UPDATE`，维护 revision/stroke_count/byte_size/sif_path/dirty |
| state | `state/ink_providers.dart` | `inkStoreProvider` / `inkWriterProvider` 改 family（workbookId）；`InkPageKey` 带 workbookId；`InkEditState.issue`；控制器只 schedule 不 await |
| ui | `ui/reader/reader_page.dart` | 实现 `WidgetsBindingObserver`：paused/detached 与退出 `flushAll`；切页/切模式 flush 当前页 |
| ui | `ui/reader/ink_layer.dart` | 载入问题时页内提示条：备份恢复=紫条，损坏跳过=红条；`IgnorePointer` 不挡笔 |

**为什么 `save` 不在抬笔路径 `await`**：整页 zlib 编码 + 写盘是 IO；抬笔只改内存
+ `schedule`。防抖 500ms 兼作"写放大"保护；生命周期是最后一道保险。

**为什么 isolate 失败要退回同步**：`Isolate.run` 在极少数环境可能起不来；
此时宁可主 isolate 多花几毫秒，也不能让这一笔没写出去。

**为什么不直接覆盖写**：断电/被杀在 write 中途会留下半个文件。顺序固定为
`旧 .sif → .bak` → 新 `.tmp` → rename 成 `.sif`；任一步失败都把旧版还回主文件。
`.bak` 是"上一版"，主文件损坏时先恢复备份，**再把备份写回主文件**，
避免下一次 save 把损坏主文件 rename 成 `.bak` 覆盖唯一的好备份。

## 4. 验证

### 4.1 宿主机

- `flutter analyze` → **No issues found**
- `flutter test` → **159 passed**（148 + 7 SIF + 4 Writer）
  - `sif_codec_test`：往返（款式/颜色/粗细/坐标/压力/t0）、空页、5000 笔体积、
    >4096 点拆分、CRC 破坏、截断/乱码、负增量与边界；
  - `ink_writer_test`：防抖只写最后一次、flushAll、失败不丢快照、同页串行；
  - `ink_edit_test`：落盘回退用例改为显式 `flush`，其余编辑行为不变。

体积实测：**5000 笔（24 点/笔）SIF = 34,705B**，远低于 400KB 上限
（坐标重复度高，zlib 压缩比大；真实试卷笔迹会更碎，仍有充足余量）。

## 5. 数据契约与已知限制

| 项 | 现状 |
|---|---|
| `ink_state` | 已有 v1 表直接使用，**无需新迁移**；`dirty` 恒 1（等第 4 周识别） |
| 会话隔离 | `ink_state.page_id` 是主键（规格 v1），所以同一页只能记一条状态；**二刷的 SIF 会话隔离要等 schema 升 v2**（加 `session_id` 到主键/索引） |
| 坐标精度 | u16 量化，实测最大 ≈0.035pt；<0.01pt 需 1/100pt 定点（v2 可加） |
| 逐点时间 | 只存 t0；足够屏显与后续识别，速度特征需要时再加 |
| 失败重试 | Writer 保存失败只保留快照，等下一次编辑/flush；不会无限重试 |
| 大文件 | 读取上限 16MB；超过按损坏处理 |
| 依赖 | 新增 `archive: 4.5.2`（pubspec 白名单内，锁 `pubspec.lock`） |
