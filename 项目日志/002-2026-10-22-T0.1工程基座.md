## 3. 踩坑记录（4 个，全部已解）

### P-01 Gradle 发行版下载必然超时

**现象**：`flutter build apk` 报 `java.net.ConnectException: Connection timed out`，栈里是 `org.gradle.wrapper.Download`。

**根因**：`distributionUrl` 指向 `services.gradle.org`，它会 307 重定向到 **github.com** 的 release 资产；本机代理对 github.com 返回 502。注意 Java 的 `URLConnection` **不读** `http_proxy` 环境变量，所以连"错误信息里提到的代理"都用不上。

**解法**：改用 `https://mirrors.cloud.tencent.com/gradle/gradle-9.3.1-all.zip`（实测 206 可取）。官方地址与还原步骤已写在 `gradle-wrapper.properties` 注释里。

**副产品**：确认了 Java 能直连外网（它自己拿到了 307），所以 `dl.google.com` / `repo.maven.apache.org` 的依赖下载不需要额外配代理。

### P-02 AGP 9.1 强制要求 NDK，即使没有一行原生代码

**现象**：
```
A problem occurred configuring project ':app'.
> Android sdkmanager did not install NDK 28.2.13676358 into E:\AndroidStudio\AndriodVirtualDevice.
```

**关键事实**：`app/build.gradle.kts` 里 `ndkVersion` 是**注释掉的**，仍然报错 —— 因为 AGP 9.1 的默认 ndkVersion 就是 28.2.13676358，它在配置阶段就要解析该 NDK 路径。

**试过但无效**：`android.builder.sdkDownload=false`（写进 `android/gradle.properties`）→ 报错一模一样，AGP 照样去调 sdkmanager。已撤回该配置。

**另一个次生问题**：AGP 自动安装走的是**已废弃的 `sdkmanager` shim**，而本机 cmdline-tools 23.0.0 的 shim 会把 `ndk;28.2.13676358` 拆成两个包名，于是出现 `Package ndk not found. Package 28.2.13676358 not found.` —— 也就是说**自动安装这条路在本机是坏的**，必须手动装。

**解法**：`android sdk install "ndk/28.2.13676358"`（新 CLI 包名用 `/` 分隔）。下载后解压 2.1 GB，E 盘 45G → 42G。

### P-03 代理变量会打断 `flutter test`

**现象**：`flutter test` 报 `Unable to connect to flutter_tester process: WebSocketException: Invalid WebSocket upgrade request`。

**根因**：环境里有 `http_proxy/http_proxy=127.0.0.1:60519` 等变量，`flutter_tester` 起在 localhost 上的 WebSocket 被代理接管。

**解法**：跑测试时清掉代理变量：
```bash
env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY -u all_proxy -u ALL_PROXY flutter test
```
> 注意：`flutter build` / `pub get` **不要**清代理（需要联网），只有 `test` 需要。

### P-04 `sdkmanager` 已被新 CLI 取代

- `sdkmanager.bat` 现在只是一层壳，会警告 deprecated 并转发给 `android.exe`；转发时参数会被重新拆分 → `"platforms;android-36"` 失败。
- `flutter doctor --android-licenses` 也因此直接返回 `Warning: The --licenses option is no longer needed.`，但 `flutter doctor` 显示 **All Android licenses accepted**，许可本身没问题。
- 新 CLI 语法：`android sdk install <pkg>/<version>`、`android sdk list --all [pattern]`、`android sdk list --all-versions`。
