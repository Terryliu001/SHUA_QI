## 1. 用户判断是对的：斜向滑动被"两个轴同时收下"了

手指画不出直线。想竖着翻页时，实际轨迹几乎总有 10°–30° 的横向分量。
旧实现（`offset = 焦点 - 内容焦点 × scale`）把 x/y 两个分量**都**照单全收，于是：

| 现象 | 机理 |
|---|---|
| 竖滑"滑了很长距离，页面只走一点" | 横向那部分位移要么被 `clampOffset` 夹死（≤100% 缩放时内容窄于屏宽），要么被本轮的橡皮筋拖走再弹回 —— **手指走过的斜线距离 ≠ 页面位移**，主观就是迟钝 |
| 放大到 >100% 后竖看会左右乱窜 | 内容宽于视口时横向真能动了，斜滑让页面斜着漂 |
| 本轮加的橡皮筋把问题放大了 | 橡皮筋原来在**两个轴**上都生效，斜滑时页面会先左右晃一下再弹回 |

## 2. 修法：一次手势只认一个轴，且偏向竖轴

新增 `DragAxisLock`（`domain/reader/scroll_math.dart`，纯函数、可单测）：

```text
decide(dx, dy, allowHorizontal):
  allowHorizontal == false            → 竖轴（横向根本推不动，不用判）
  位移 < 6dp                          → 还没定（避免抖动误判）
  |dy| ≥ |dx| × 0.7                   → 竖轴
  否则                                 → 横轴
project(dx, dy, vertical)             → 另一轴归零
```

- **0.7 的竖轴偏好**意味着：偏离竖直 55° 以内都算竖滑，只有明显横着划才判横轴。
  阅读器里"手歪一点"远比"想横向平移"常见，这个偏置是有意的。
- 判定阈值 6dp：太小会被抖动误判，太大会有起手迟滞；6dp 在真机上察觉不到。
- **判定后整段手势不再改轴**（中途跳轴会让画面顿一下）。
- 内容窄于屏宽（≤100% 缩放）时**起手即锁竖轴**，连判定都不用等 —— 这是最常见的情况。
- 甩动速度也投影到锁定轴：斜着甩一把不会横着飘。
- 橡皮筋只在锁定轴生效：`_clampOffset` 新增 `overscrollVertical/Horizontal` 开关，
  另一轴硬夹紧 —— 斜滑时页面不再左右晃。

## 3. 验证

**单测**（`test/drag_axis_lock_test.dart`，7 例）：阈值、纯竖/纯横、26°/35°/45°/60° 斜滑的判定、
横向不可推时直锁竖轴、投影归零、"斜线长 141 只取 100 竖位移"。

**真机**（暗纸卷子，45° 斜拖 1000×1000、3 秒慢速）：
- 拖动过程中截图：页面左右留白**对称**（≈105 / 1435 预览像素），与静止时一致 → **零横向漂移**；
- 同一手势里内容从第 17/18 题滚到第 13/14 题 → **竖向位移完整生效**。

> 说明：我原本想用像素测出"横向位移 = 0"，但暗纸下纸面与背景只差 ~10 灰阶，
> 边缘检测的噪声大于信号（测出来 2421/2509/2365 波动），所以改用
> "留白是否对称"这种目视可判的指标 + 单测钉住数学。这个测量方法上的取舍写在这里，免得下次重复踩。

## 4. UI 设计第二版（切片：设置 / 空态 / 搜索 / 对齐）

第一版做的是"系统与骨架"（令牌/主题/转场/按压反馈）。这一版开始逐屏细化：

| 屏 | 改动 | 理由 |
|---|---|---|
| 设置页 | 分组标题与卡片**左对齐同一条竖线**（原来标题 32dp、卡片 16dp）；标题降为 `onSurfaceVariant` + 字重 600 + 字距 0.6 | 分组名是导航信息，不该比内容更抢眼（iOS 设置页的做法） |
| 空态（书架/记录/错题共用） | 图标落进 **96dp 软圆底 + 发丝描边**，间距收紧 | "空"看起来是有意的留白，而不是渲染失败 |
| 书架搜索框 | 顶栏里改成**胶囊填充式**（前置放大镜、无边框） | 与 chip / 按钮同一套语言；提示语改成"搜索标题 / 标签 / 文件夹" |
| 卡片 | 主题统一后自动变成 **圆角 20 + 发丝描边 + 零投影** | 两套主题一套规则 |

## 7. 已知限制

| 限制 | 说明 |
|---|---|
| 横轴锁定后横向平移需要"更横"地划 | 这是竖轴偏好的代价；0.7 这个系数可调（改一个常量 + 一条单测） |
| 双指捏合期间不做轴向锁定 | 捏合本来就是两轴同时变，锁轴没有意义 |
| UI v2 仍是切片 | 设置页还没有逐行图标/说明重排；记录/错题两页还是老样子；字阶与中英混排未细调 |
