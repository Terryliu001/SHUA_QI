## 1. 三个症状与根因

### 症状 1：暗色下所有 PDF 一片死黑 —— **根因是矩阵单位错误（一行修复）**

`ColorFilter.matrix` 的输入通道与第 5 列偏移都是 **0..255 的字节值**，不是 0..1。
`NightTint._buildMatrix` 把归一化的 ink 色（≈0.91）当偏移填进去：

```text
白纸 R: (-0.816)·255 + 0.91 ≈ -207 → 钳到 0 → 黑
黑字 R: 0 + 0.91 → 钳到 0 → 黑
```

所以整页纯黑，且归一化口径的单测（`m[0]*r+m[1]*g+m[2]*b+m[4]`，r∈0..1）
完全看不出来——它数学上自洽，只是单位错了。修复：偏移列 ×255；
单测改成 **字节口径**（`NightTint.applyByte`）并断言"白纸→纸色≠0、黑字→亮墨>200"，
这类事故以后宿主机就能拦住。

### 症状 2：滚动模式 100% 滑动不流畅、多次捏合后卡顿 + 显示异常 —— 三个根因

1. **`RenderTransform` 没在走合成层**。相机矩阵每帧变，但子树
   `needsCompositing == false` 时 Transform 只把矩阵压进 canvas：
   可见页位图 + 噪点纹理 + 阴影**每帧全部重新光栅化**（2 页 A4 ≈ 12.8MP/帧）。
   修法：每页包 `RepaintBoundary`（PageLayer）→ Transform 推真正的
   TransformLayer，纯平移变成合成器搬缓存贴图；写字时墨迹层重绘也不再带动 PDF 位图。
2. **捏合后位图内存暴涨触发淘汰与 GC**。上限 4096px 时 A4 一页 95MB，
   三页 285MB > 200MB 缓存 → 每次清晰度升级互相挤掉、挤掉又现渲。
   收敛到 3200px（一页 52MB，三页 156MB），代价是 200%+ 放大略软
   （真无损要等分块渲染 T1.5.1，规格已知项）。
3. **位图落在半个像素上**。1 倍时 fit-width 位图与屏 1:1，但位移是浮点 →
   每帧一次双线性重采样（又糊又慢还有细抖）。`_publishCamera` 现把位移
   取整到设备像素（2.5dppx 下台阶 0.4dp，不可见）。

另修一个 T2.1 引入的真实布局缺陷：`PageLayer` 挂墨迹层后返回的 `Stack`
**只有 Positioned 子节点** → 撑满父级约束；分页模式里父级是 `Center`
（松散约束 = 整个视口），页面被拉成视口比例。现在外面钉了 `SizedBox(页宽×页高)`。

### 症状 3：落笔粗细突变 + 抬笔后粗细突变 —— 两个来源，一并根除

| 来源 | 机理 | 修法 |
|---|---|---|
| 落笔/抬笔读数不可信 | Android 的 DOWN/UP 事件压力常报 0（或 1.0），直接映射就是发丝/最粗 | `_pressureOf`：`<=0.02` 沿用上一个有效压力（落笔基线重置为中性 0.5），`>=0.999` 视为无压感取 0.5；收尾点用真实最后压力（旧代码硬编码 0.5、t=0，是尾巴变粗的第二个来源） |
| 活笔/死笔两套几何 | 活笔逐段 drawLine（压感连续），死笔按平均压感归 3 档（1.6/2.6/4.2）重画 → 抬笔瞬间整笔换宽 | **新 `InkRibbon`：宽度量化 24 档（0.148pt/档，400dpi 下不可见），每档一条 Path**；活笔流式 append、死笔整笔重放，**同一份代码同一份几何**，抬笔=把几何从活动层搬到已提交层，像素级一致 |

配套：压感 EMA 平滑（0.45，约 3 个采样点 ≈13ms）把起笔的读数跳变变成
自然提按；起笔画圆点（笔尖落纸本来就有点）；`test/ink_ribbon_test.dart`
用"流式 vs 整笔逐档包围盒相等"把这条承诺钉进测试。

结构变化（`ink_painters.dart` 重写）：每笔刷一条 ribbon（钢笔/圆珠笔不透明
srcOver，荧光笔 multiply）；**荧光笔改为垫底先画**（原来最后画，会把已写的
字再乘一次色）。代价：已提交层重绘从 3 条 Path 变最多 72 条，仍远低于逐段绘制。

## 2. 顺手完成：笔刷工具栏（T2.2 前半）

- `state/ink_tool_provider.dart`：全局唯一笔刷（不分卷），落盘
  `setting` 键 `ink.default_brush`（新增键名），读失败静默回落钢笔。
- `ui/reader/ink_toolbar.dart`：右下角浮层，钢笔/圆珠笔/荧光笔**文字**分段
  （Material 里钢笔与圆珠笔没有可区分字形，文字比图标诚实）；选中态
  100ms 变色、48dp 触控目标；按钮吃掉指针，笔尖点它不会落墨。
- 只影响**之后**画的新笔；已落笔的笔保留原笔刷（笔迹是事实）。
- 荧光笔选择后自然可用：等宽 14pt + multiply + `excludeFromOcr`（原有语义接通）。

**不做**：宽度滑块。SIF v1（§5.4）的 stroke 头没有自定义宽度字段，
加宽度会破数据契约，记为 v1.1 议题。

## 6. 待你手写笔复验（3 步）

1. **粗细连续**：滚动模式用笔写几行——起笔不突然变粗、行笔提按自然、
   **抬笔瞬间整笔宽度不变**（这是本轮最重要的验收点）；写轻一点和重一点各试；
2. **三支笔**：工具栏切圆珠笔（等宽细）、荧光笔（宽、半透明、字仍可读、
   且字上画荧光不会把字染黑）各写几笔；切暗色再写——笔迹应是暖白墨；
3. **滚动跟手**：100% 拖动与甩动是否比之前顺；反复双指放缩几次后再滚动
   （之前"卡顿+显示异常"的场景）——现在页面比例应始终正确、不再发糊发白。
