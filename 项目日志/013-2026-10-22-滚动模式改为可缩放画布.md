# 013 · 滚动模式重构为「可缩放画布」

| 项 | 值 |
|---|---|
| 日期 | 2026-10-22（GMT+8，15:28–15:45） |
| 用户反馈 | 滚动模式双指缩放不跟手，**做不到"在哪里放大就放大哪里"**；要求借鉴成熟设计重构 |
| 结论 | 放弃 ScrollView，改为 2D 仿射画布；焦点缩放由公式保证；单指平移与 200% 档位已真机验证 |

---

## 1. 为什么前两版做不到"哪里放大就放大哪里"

前两版都是在 **ListView 里塞缩放**：要么 `InteractiveViewer`（抢手势），要么自己数指针后"改布局宽 → 重排 → `jumpTo` 校正偏移"。

这条路有三个绕不过去的天花板：

1. **慢半拍**：`setState` → 重排 → post-frame `jumpTo` 校正，视觉总是比手指晚一帧以上。
2. **没有"焦点"概念**：布局是自上而下重算的，`scale` 只是一个宽度系数，
   你捏住的那一点在重排后落到哪里，只能靠事后补偿，而且补偿本身又慢半拍。
3. **位图风暴**：页宽每帧变 → 每帧请求新尺寸位图（一次捏合 60 帧 ≈ 60 张 12–50MB）。

## 2. 新模型：一块画布

成熟 PDF 阅读器的做法是把"滚动画布化"——**内容排一次版就固定不动，屏幕位置由仿射变换算出来**：

```text
屏幕坐标 = 内容坐标 × scale + offset
```

- `scale`、`offset` 是唯一的状态；
- 单指拖动只改 `offset`；
- 双指同时改 `scale` 与 `offset`；
- 只渲染与视口相交的页（懒加载靠"可见区间计算"，不靠 Sliver）。

### 焦点缩放的数学（"在哪里放大就放大哪里"就靠它）

手势开始时把焦点换算到内容坐标，之后**每一步都让这个内容点钉在焦点屏幕上**：

```dart
// 开始
focalContent = (focalScreen - offset) / scale;

// 每一步
scale'  = clamp(startScale * gestureScale, 1, 4);
offset' = focalScreen - focalContent * scale';   // 反解
```

因为焦点内容点在变换后仍然映射到同一个屏幕点，所以**捏住哪里就在哪里放大**，
而且这是纯矩阵运算，没有任何重排，天然跟手。

### 顺带解决的三件事

| 问题 | 解法 |
|---|---|
| 位图每帧重建 | `_qualityScale` 冻结，停手 250ms 才升级；期间 GPU 拉伸 |
| 手势竞技场冲突 | 没有 `Scrollable` 了，直接 `GestureDetector.onScale*`，单指/双指统一 |
| 内容比视口窄时贴边 | `_clampOffset` 里横向居中、纵向顶端对齐 |
| 滚动惯性 | 停手后按 `velocity × exp(-k·dt)` 衰减，撞边即停（约 20 行，不引物理引擎） |

## 3. 真机验证（OPPO OPD2601）

| 场景 | 结果 |
|---|---|
| 切滚动模式 | ✅ 内容横向居中，停在上次阅读页（3/4） |
| 单指拖动 | ✅ 内容跟随平移，页码同步变化 |
| 档位菜单 200% | ✅ 以视口中心放大，公式清晰（位图按新倍率升级） |
| 放大后横向位置 | ✅ 以中心缩放，左右按预期被裁 |
| **双指捏合** | ⏳ **adb 注入不了多指，需手指验**（数学上已是焦点缩放） |

---

## 4. 与分页模式的分工（现在很清晰）

| | 分页 | 滚动 |
|---|---|---|
| 翻页/滚动 | 左右按钮 | 单指拖动（画布平移） |
| 缩放 | 页内 `InteractiveViewer`（每页独立控制器） | 画布 `scale`（焦点缩放） |
| 放大后平移 | 页内单指平移 | 天然支持（拖动即平移） |
| 超界 | `InteractiveViewer` 边界 | `_clampOffset` 夹紧 |

## 5. 待你手指验证

1. 滚动模式双指捏合：**是否在捏合处放大**（不再是屏幕中心）；
2. 捏合过程是否跟手、不闪烁；
3. 松手 250ms 后画面变清晰一次（设计如此）；
4. 单指拖动有没有惯性、撞边是否干脆。

若 1 不成立，说明 `GestureDetector` 的 `localFocalPoint` 与我假设的坐标系不一致，
需要改用 `details.focalPoint` 并做全局→局部换算——这是唯一还需要实测确认的点。
