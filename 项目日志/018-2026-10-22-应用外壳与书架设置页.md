## 2. 应用外壳：四 tab + 自适应导航

| 决策 | 理由 |
|---|---|
| 四个主 tab：**书架 / 记录 / 错题本 / 设置** | P0 的四个常驻面（§3.1 REQ-01/11/13）。阅读器**不进 tab**——它是全屏 push 路由，刷题是主流程，不该被 tab 框架包住 |
| 宽屏（≥600 逻辑宽）左侧 `NavigationRail`，窄屏底部 `NavigationBar` | 主战场是平板（横 1200 / 竖 848 逻辑宽），底部 bar 在平板上要么被拉垮要么够不着；600 阈值下平板任何方向都走 rail，手机走 bar |
| `IndexedStack` 保活 | 书架滚动位置、导入中状态，切去设置再回来不该丢 |
| 路由表顶层只剩一条（`AppRoutes.shell`） | tab 切换是外壳内部状态，不进路由栈——否则系统返回键会一级级退 tab，而不是直接退出阅读器 |
| rail 顶部放"刷起"小字名牌 | rail 不需要 FAB（导入 FAB 在书架内容区），空着不如给个品牌位 |

## 3. T1.4 书架收尾（四项）

| 项 | 做法 |
|---|---|
| **长按菜单** | 底部浮层（24 圆角 + 拖拽把手）：重命名 / 删除 / 导出。**导出置灰 + 锁形角标 + "规划在 T7"**——能点但没反应是假功能 |
| **重命名** | 对话框预填标题；空标题当作取消（库里 `title NOT NULL`，不给用户无名卷） |
| **删除** | 确认对话框说清连带范围（PDF/缩略图/将来的笔迹与识别记录）；**先删库后删目录**——库里没了，残留目录会被下次启动的 `sweepOrphans` 收掉；反过来会留永远打不开的幽灵记录 |
| **搜索** | AppBar 标题位原位换成 TextField；`filterByQuery` 纯函数（标题包含、忽略大小写、trim），书架上限 50 卷客户端过滤零成本；"有卷但无结果"是单独空态，不露"导入第一份"引导 |
| **下拉刷新** | `RefreshIndicator` + `invalidate` 后等新 future 完成（转圈在数据真正回来后收）；列表 `AlwaysScrollableScrollPhysics`（空结果态也要能拉） |
| **文件损坏态** | 新 `workbookHealthProvider`（family，探测 `source.pdf` 在不在）：损坏 → 整卡 55% 不透明 + 缩略图红色"文件缺失"角标 + 点击弹"长按可删除后重新导入"，而不是让用户点进去才撞错误 |

## 4. 设置页（T6.1 先行子集：真功能 + 诚实置灰）

**真实生效的两组**：

- **主题**：跟随系统 / 浅色 / 深色（`SegmentedButton`）→ 写 `app.theme_mode`（新 setting 键，`AppSettingKeys`），重启保持。这是 017 暗色夜读的自然延伸——**做得好看还不够，要能让用户自己选**。
- **阅读默认**：默认模式（分页/滚动）+ 默认纸感（五色块，填充按当前强度混合，拖滑条能实时看到结果）+ 默认强度 → 写 `reader.default_*` 三条（`ReaderPrefsStore.loadDefaults/saveDefaults`）。语义：**只影响之后新读取的卷**；正在读的卷有自己那份 `reader.view.<id>`，不被打扰。

**诚实置灰的两组**：AI 配置（"规划在 T6.1"）、存储统计（"规划在 T7.5"）——置灰 + 锁形角标 + 一句规划位置。

**关于**：名称 + tagline + 版本（`AppInfo` 常量与 pubspec 的 0.1.0 同步；不引 package_info_plus）。

## 7. 踩坑记录（对后人有用）

1. **Riverpod 3.4.3 已移除 `StateNotifier` / `StateNotifierProvider`**（本次 analyze 直接 undefined_class）。
   主题模式改用 `Notifier` + `NotifierProvider`；依赖在 `build()` 里 `ref.watch` 取
   （`watch` 只允许在 build 内，方法里 watch 会抛），之后的方法用同一份。
2. **`FutureProvider.family` 的声明类型是函数类型**：`FutureProvider<bool> Function(String)`，
   直接写 `FutureProvider<bool>` 会 invalid_assignment（readerPrefs 早就是这么写的，抄它）。
3. **Dart 的 const 字符串插值是合法常量**：`'${AppInfo.tagline}\n版本 ${AppInfo.version}'`
   全是 const 成员 → 整个 Text 可以是 const。prefer_const 系列 info 在严格 lint 下
   必须逐个消（本项目 analyze 要求零 issue，info 也算）。
