## 1. 用户反馈三处（T8.2 补记）

1. **判定圆点**：缩略图右上角 → **元信息区右下角**（`Row(end)` + `GradeDot(12)`），不再遮题面。
2. **题面图高度**：`Expanded` 填满 → **固定 `AspectRatio(3/2)`**（高 ≈ 0.67W，约为原来的 2/3），网格
   `childAspectRatio 0.78 → 0.92`；元信息区占比更大，卡片更紧凑。
3. **标签条「＋」**：末尾加 `_AddTagChip` → 输入标签名（`_promptTagName`）→ 多选题目
   （`_pickForTag`，**默认勾选「未归纳」的题**）→ `FavoriteStore.appendKnowledgeTag`（逐条读改写、去重）→ 刷新。
   「添加知识点标签并批量归类」闭环，不产生空标签。

## 2. 看题页（T8.3a）

### 2.1 路由与定位

- 新路由 `/favorite_question` + `QuestionViewArgs(favoriteId)`（`ui/router.dart`）。
- `ReaderRouteArgs` 加 `initialQuestionId`；`reader_page` 在切题结果加载后**一次性定位**
  （`_pendingQuestionId` → postFrame 里 `_panelOpen=true` + `_selectBundle` + `_jumpTo`，然后清空）。
  用 `!regionSet.isEmpty`（RegionSet 没有 `isNotEmpty`）。

### 2.2 看题页（`ui/favorites/question_view_page.dart`）

- 布局：AppBar（题号 + 回看出处 + 取消收藏）→ ListView：删卷提示条（`sourceDeleted`）→ 题面卡 →
  我的作答卡 → 判定与参考答案卡 → AI 问答卡（历史气泡 + 流式 + 输入框）。
- 快照读取走 `FavoriteStore` 新方法：`loadChat/saveChat`（`{turns:[...]}`）、`loadGrading/loadAnswerNote`；
  图片直接 `vault.file` + `Image.file(fit: contain)` + errorBuilder 占位（迁移无图不空白）。
- **AI 追问（快照链路）**：历史 = 快照 `chat.json`；发送 = `AiService.chat`（`aiServiceProvider(favoriteId)`），
  payload 从快照元信息构造（`buildQuestionAiPayload`），attachments = 快照题面图 + 作答图
  （直接读字节构造 `AiImageAttachment`）；流式气泡显示 thinking 提示 + 正文；
  完成 append 写回快照；失败给可重试的错误气泡（`ChatTurn.error`，**不落盘**）。
- **不复用 `AiChatPanel`**：它绑定 reader 的 payload/快捷动作/onPersist 体系，复用要复刻约 300 行
  `_aiSend` 且判题落点语义不同（快照 vs 原卷 grading）。看题页用轻量对话区（`ChatContent` 渲染）。
- 回看出处：`sourceDeleted` 时置灰（tooltip 说明）；取消收藏有二次确认，成功后 pop 回收藏夹并刷新。
