## 2. 真机抓出的三个问题（都已修）

### 2.1 「关于」三个入口整块不渲染 ⚠️ 严重
- **现象**：设置页滚到底，「数据」分组正常，但「关于」里只有产品名 + 版本芯片，**三个入口卡片不见了**（截图 03–05）。
- **根因**：`_AboutEntries` 里 `Row(crossAxisAlignment: CrossAxisAlignment.stretch)` 放在 `Column` 内 —— Column 给子节点的高度是**无界**的，stretch 直接崩掉整块子树。
- **修法**：外面套 `IntrinsicHeight`（先把高度定下来，stretch 才有意义）。修完截图 06 三个卡片正常。

### 2.2 裁剪窗的图没放大 + 提示被图盖住
- **现象**：进裁剪窗后图片是"适配视口"的原始大小，取景框里大半是遮罩，裁出来会是一张小图；底部提示文字被图片压住看不见。
- **根因**：① 没做初始 cover 变换；② 提示语在 Stack 的图片层之下。
- **修法**：① 初始把图缩放到**刚好填满取景框**；② 提示语提到最上层并加半透明底。
- **第二次翻车**：`InteractiveViewer` + `Matrix4` 的组合在新版 vector_math 下算错——`translateByDouble` 会把**已缩放的矩阵再乘一遍**（`t1 = m[0]*tx + m[4]*ty + …`），平移被缩放系数放大。两次尝试（post-frame callback、换 API 名）都不对。
- **最终修法**：**不用 InteractiveViewer**，缩放与平移自己管（`_scale` / `_offset` + `GestureDetector` 的 `onScaleStart/Update`），矩阵顺序固定为 **先平移后缩放**（`M = S·T` → `p' = S·p + t`）。裁剪换算与显示矩形口径一致（`displayed = (offset, base*scale)`）。

### 2.3 缓存清理结果看不见
- **现象**：清完了，但"已清理 XX"显示在列表中间，用户看不到 → 以为没清。
- **修法**：结果挪到**底部固定区**（按钮行上方），清完立刻可见。

另外顺手修了一处文案：版本说明顶部提示里的 `**真的**`（markdown 星号）直接显示出来了，改成「真的」。

## 3. 一个要记住的坑：导出过程中被杀掉会留下**截断的 zip**

现象：安装新包（`adb install -r` 会杀掉正在运行的 app）时，如果那一刻正在导出，下载目录里会留下一个
**只有 local header、没有中央目录**的坏包（19.9KB），Python `zipfile` 报 "File is not a zip file"。

- 结论：**不是导出逻辑的 bug**，是"复制到下载目录"这件事被中途杀了。
- 已有兜底：恢复流程第一步就是读 manifest，坏包会被明确挡掉（「不是本应用的备份」），**不会误伤数据**。
