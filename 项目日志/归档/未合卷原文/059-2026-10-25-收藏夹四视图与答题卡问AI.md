## 1. AI 归纳：先确认，不误操作

用户口径：默认只动"上次归纳之后仍然未归纳"的那部分；所有归纳行为（AI 归纳、手动编辑、标签条 ＋ 批量归类、多选点亮）都算一次归纳。

实现：
- `setting` 新键 `favorite.last_tag_at`（UTC ms）：上述任一行为成功后写一次；
- 「AI 归纳」不再直接跑：先弹 **确认清单**——每行 `第 X 题 / 卷名`，标注「· 新增」，默认勾选
  `isNewSinceTag(createdAt, lastTagAt)`（从未归纳过 = 全选），提供 **全选 / 清空** 与逐条勾选，
  按钮写「归纳 N 题」（0 时禁用）；
- 归纳过程中 chip 显示「归纳中…」；失败不写半份；只改**仍无标签**的题。

纯函数 `isNewSinceTag` 与 `searchFavoriteSets` 放进 `favorite_set_plan.dart` 并加单测。

> 真机：当前 1 道未归纳（旧收藏）→ 弹窗写"共 1 道未归纳，其中上次归纳后新增 0 道（默认勾选）"，
> 默认 0 选、按钮禁用——正是"不误操作"想要的效果（截图 `10-ai-tag-confirm.png`）。

## 2. 「原卷已删」降噪

- 题卡：卷名 `Flexible` 收缩 + 浅色后缀 ` · 原卷已删`（不红、不抢眼，且长卷名省略时状态仍在）；

## 3. 「按试卷」= 文件夹卡

- 一张卷一张卡：左上文件夹标签（图标 + 卷名 + N 题）、中部最多 3 张题面预览、页脚最近更新时间；
- 点开 → 新页 `FavoriteWorkbookPage`（`/favorite_workbook`）：这一卷的收藏按更新时间倒序铺卡，
  点开看题、长按重刷/取消收藏；
- 长按文件夹卡：**重命名试卷**（改 `workbook.title` + 同步所有收藏快照的 `workbook_title`，
  与书架**双向**）、**在书架中查看**、**删除本卷收藏**（只删快照，不删原卷，二次确认）。

双向同步验证：收藏夹改 `…-x` → 书架卡片立刻变；书架再改回 → 收藏快照标题回原值（DB 核对通过）。

## 5. 多选：组卷 / 点亮知识点

- 进入多选后**统一铺成题目卡**（不论当前在哪个视图；否则文件夹卡/组卷行点不动）；
- 底部两个键：
  - **组卷** → 居中弹窗：已有组卷列表（名字+题数）/「新建组卷…」/ 取消；
  - **点亮知识点** → 居中弹窗：已有知识点可**多选**（FilterChip）+「新建知识点…」+「点亮 N 个知识点」；
- 原「加入组卷 / 新建组卷」两个键与长按菜单里的「加入组卷」都收敛到同一套弹窗；
- 点完自动退出多选并提示结果；两种操作都会更新 `favorite.last_tag_at`。

> 真机：选 1 题 → 组卷弹窗（set-2q / 测试 / 新建）→ 取消；点亮知识点弹窗（英语词汇/政治理论/极限/函数）
> → 选「极限+函数」→ 写库成功（DB `2.: 极限,函数`，`last_tag_at` 更新）（截图 `05–08`）。

5. 按试卷的文件夹卡预览最多 3 张，第 4 张起不显示（题数仍准确）。
