## 2. B2 判题（对答案 / 改卷 / 批量 AI 判）

- 新增纯函数 `judgeLocally`（可信 / 不可信 / 无答案 / 无作答）+ 7 例单测。
- 单题「对答案」：无参考答案 → 面板置灰；有答案无作答 → 只展示答案；本地可信 → 落结论 + 指示点；不可信 → 黄点 + 询问「交给 AI 判」。
- 「改卷」：只跑有参考答案的题；本地可信的立即落；判不了/不可信的汇总后询问是否 AI 后台判；手改优先；有进度条「AI 后台判 done/total」与停止。
- 多选「AI 判」：已有答案不重复生成；没有才 solve；无作答跳过；判完写该题对话 + 指示点；修了「补答案后 provider 已 invalidate、取不到参考答案」的 bug。
- 真机：选中无答案题 4，对答案按钮置灰、显示「这道题没有匹配到答案」；改卷后指示灯更新。

## 3. B3 重刷（本次重点）

- **数据 v9**：`answer_log` 加 `attempt_id` / `favorite_id`；唯一索引改 `(question_id, day, origin, attempt_id)`；同一天多次重刷各留一行。
- 新 `RedoAttemptStore`：`favorites/<id>/redo/<attemptId>/meta.json + paper.json + ink/pN.sif`；旧 `ink/pN.sif` 一次性迁移成 `legacy-<时间>`，不丢笔迹。
- 重刷页：点「重刷」打开**空白新答题卡**；退出弹「保存 / 不保存 / 继续写」；保存落 meta + 记录；不保存删目录与记录；App 被杀保留 draft，下次可看到「未保存」。
- 看题页：原来的单张重刷图改成**重刷记录列表**（时间 / 张纸 / 组卷名 / 未保存），点某次打开继续改，长按（⋯）删除该次。
- 时间线：重刷/组卷按 attempt 分卡，展开是题目列表；点题打开**那一次** attempt，不再只弹提示。
- 真机：新建空白→写一笔→返回弹保存→保存→看题页列表出现 2 条→时间线出现「重刷」卡→展开→打开该 attempt，笔迹正确。

## 4. B4 笔刷 HUD + 图形吸附

- 粗细滑条右侧改成**真实笔触样本 + 数值**；画布上的大小提示圈加「笔尖 42 / 橡皮 18」标签。
- 新增纯 Dart `shape_recognition`：线/矩形/正方形/圆/椭圆/三角（直角/等腰）/平行四边形；模板粗分类 + 几何拟合 + 残差拒识；6 组正负样本单测。
- 交互：停笔 500ms 预览 → 抬笔确认；继续移动取消；仅钢笔/圆珠笔；预览标签「矩形 · 松手确认」+ 轻震动；可撤销。
- 修正了正方形被 PCA 主轴识别成旋转大矩形的问题，改为**最小面积外接矩形**逐度搜索。
